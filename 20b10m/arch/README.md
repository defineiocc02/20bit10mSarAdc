# arch/ —— 架构的 Python 数值复核

> 独立于 `model/`：**不 import、不读 `model/results.json`**，参数全部在 `arch/params.py`，从零算。
> 跑法：`cd 20b10m && python3 -m arch.verify`（约 2 s；`--json` 只出 JSON）
> 最近结果：**31 项，23 PASS / 6 WARN / 2 FAIL**（`arch/results.json`）

## 1. 冻结的架构（代码即口径）

| 项 | 值 | 为什么是这个 |
|:---|:---|:---|
| 转换链 | **单套**（RA/CT2/Cmp/flash/数字） | A/B 相 ΦC2 不重叠，CT2 空闲 60 ns |
| DAC1 | **18 × (128×27 fF)**，片内 7b + 跨片 3b unary | 8 片并联 = 28 pF，1024 单位 = 2^10 |
| 一级 | **10 有效位 / 10 次判决**（4 flash + 2 SAR + 4 fine） | 池里没有 0.5 LSB1 元件 |
| 二级 | **11 bit** + 8× 模拟重复 | 19 拍 × 2 ns = 38 ≤ 40 ns |
| 增益 | **A_RA = 32**（由 C_FB=864 fF 定）；**k_INC = 0.492** | 电压增益与电容分压是两个量，不能混 |
| C_INC | **864 fF**（32 单位） | unitcap 合规；与 DAC2 阵列同块，可共质心 |
| 桥接 | **28 fF 保留**（理想 27.43） | +2.1% 重叠 → 非单调但无缺码；需 1 个系数 |
| 系数 | **142 个独立 / 160 槽** | 18 个片权与逐位权共线，秩亏 18 |
| 时序 | 20 tick × 5 ns；ΦC0/1/RA/C2 = 2/3/5/8 tick | 90 ns 转换 + 10 ns 换相 |
| 输出 | 22 bit @ LSB=0.5 LSB_total | 量程 141% FS，余量给失调 |
| 引脚 | QFN-48（29 功能 + 19 电源地） | 见 `interface/pinout_qfn48.csv` |

## 3. 两个 FAIL：都是真问题，不是笔误

**T5　ΦC2 在悲观 Cmp2 下装不下**
- 名义（Cmp2=0.6 ns，含 0.9 建立 + 0.3 逻辑）→ 19×1.8 = **34.2 ns**，占 86%，PASS。
- 悲观（Cmp2=2.36 ns，`spec_tree` 的值）→ 19×3.56 = **67.6 ns**，超 27.6 ns。
- 单拍预算只允许 **Cmp2 ≤ 0.91 ns**。
- 处置：Cmp2 实测前不得冻结 ΦC2；退路是借 ΦRA 3 ns（架构退路①）或 M 8→6。

**C2　校准残差的口径差 10 倍**
- 按文档「每权测量噪声 2.8 LSB20」推：n=1 → **21.2 ppm**，n=16 → 5.30，n=256 → 1.32。
- 文档写 2.3 / 0.57 / 0.14 ppm。同一组数差 ~10×。
- 反推：文档的 2.3 ppm 对应 **0.30 LSB20/权**，不是 2.8。
- 处置：先定「2.8 LSB20 是每权噪声还是每码噪声」，再谈 n。1/√n 标度律本身成立（4.00×，PASS）。

## 4. WARN 里最该看的三个

- **N5**：换回 amp4.8 口径 DR 只有 **102.25 dB**（满量程 102.61）。**架构裁决：DR 以满量程 10 Vpp 定义**，amp4.8 只作历史对比。
- **N7**：满量程下 ρ 上限 0.575（当前 0.449，余量 +0.13）；amp4.8 下上限 0.424（当前已超）。ρ 是唯一能翻转结论的假设。
- **D1**：28 fF 有 31 个回退步（每个主 LSB 边界）。不是缺码，是重叠；**必须留 1 个 DAC2 子阵增益系数**，否则 42 LSB2 锯齿 INL。

## 5. 改动规则

1. 先改 `params.py`，再跑 `python3 -m arch.verify`；表里的数不手写。
2. 任何 `FAIL` 要么改设计，要么改判据，**不许改判定条件让它变绿**。
3. `arch/` 不引用 `model/`；两条证据链要能独立复现。
4. 新增检查必须能失败（先确认它在坏参数下确实报 FAIL）。
