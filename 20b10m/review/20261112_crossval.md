# 技术有效性交叉验证（2026-11-12）

> 目的：把"模型跑出一个数"升级为"多 seed、多工作点、可跨 0 检验的结论"。
> 脚本：`model/crossval.py`；原始数据：`model/results/crossval/results.json`；汇总：`summary.csv`。
> 协议：**K=10 独立 seed（1000–1009）**，同一 seed 下 base/tech 配对；2 个输入频率、2 个 FFT 长度；
> 95% CI 用 t₀.₉₇₅,₉ = 2.262；判定 POSITIVE / NEGATIVE / INCONCLUSIVE / PASS / CONDITIONAL。
> 图：`docs/figures/f6_crossval.png`（另一组 seed 2000–2009 的图见 f2/f3/f5，作为独立复现）。

## 1. T1 8× 平均：与解析式对上了

模型：`tracking_noise` 把 RA 宽带噪声按 AR(1) 因子压缩：

```
F = 1/M + 2/M² · Σ_{k=1}^{M-1} (M−k)·ρ^k          ρ=0.61, M=8 → F=0.3927
预测 ΔSNDR = 10·log10[(σ_RA² + σ_other²) / (σ_RA²·F + σ_other²)]
σ_RA=24.0, σ_other=√(17.3²+9.7²+2.9²+9.7²)=22.1 µV
→ 预测 +1.714 dB
```

实测 **+1.687 / +1.701 dB**，差 **−0.027 / −0.013 dB**。这是本报告最强的一条：
不是"模型自己说自己"，而是**统计结果与解析式一致**。

> 仍不能声称：这验证的是"模型里的 AR(1) 假设自洽"，不是"硅上 8× 真有 1.7 dB"。
> ρ=0.61 是反解值，不是实测。

## 2. T2 CAAZ：3.6 dB 里只有 0.6 dB 是 AZ

| AZ 共享度 | ΔDR vs 无 CAAZ |
|:---:|:---:|
| 1.0（完全共享） | +3.65 dB |
| 0.7 | +3.46 dB |
| 0.0（各自独立） | +3.05 dB |

- **通用两点平均**贡献 ~3.05 dB；**AZ 抵消**只多 **+0.60 dB**。
- 与旧结论"3.04 dB 是通用平均、AZ 只 +0.58"一致，10 seeds 下复现。
- 频率 0.1→2 MHz，收益 3.65→3.21 dB，10/10 正。

> 代价：CAAZ 输出速率减半（10 MS/s → 5 MS/s），这是"用速率换噪声"，不能与 10 MS/s 模式同时宣称。

## 3. T3 片级 shuffle：SFDR 稳健，DR 不稳健

- **SFDR**：100 kHz **+22.3 dBc**，2 MHz **+21.7 dBc**，10/10 正；失配越大收益越大（10→100 ppm：+15.2→+23.3 dBc）。
- **DR**：crossval 段（1000–1009）**+0.86 dB [−0.30, +2.03]**，8/10 正 → 不显著；
  图段（2000–2009）**−1.7 ± 0.8 dB** → 显著为负。**两段方向相反**。

结论：**"用 1 dB DR 换 21 dBc SFDR"这句话作废。** 正确说法是：
> 片级随机选片把固定片间失配打散，SFDR 稳定改善 ~20 dBc；DR 的变化取决于具体失配实现，不可引用。

这也是本轮交叉验证最有价值的一条：**单 seed 段会给出一个看似干净、实则方向错误的 DR 数**。

## 4. T4 校准：三种口径必须分开

| 口径 | 值（10 芯片） | 说明 |
|:---|:---|:---|
| raw INL | **17.76 ± 4.40 ppm** | σu=0.2%，8 片×128 单位；seed 间差异大（4.4 ppm） |
| 有限样本校准（n_avg=16） | **0.64 ± 0.04 ppm** | 拟合权重 + 测量噪声投影；这是旧说的"0.3–0.65 ppm" |
| out-of-sample（偶→奇） | **1.87 ppm [1.47, 2.28]** | 没见过一半码，评估另一半；**略超 ±1.5 ppm 目标** |

- in-sample 特征投影在数学上 ≈0（65 个特征张成 1024 点），**不能当结果**；旧图里的 0.3 ppm 是有限样本口径。
- out-of-sample 1.9 ppm 说明：**校准能泛化，但按 ±1.5 ppm 目标还差一点**；要压到 1.5 以下，需要更多平均或更宽的特征（例如加桥接/半组项）。
- σu 线性：0.1/0.2/0.4% → 8.49/16.97/33.95 ppm，斜率 84.86 ppm/1%，三档偏差 7×10⁻⁵。

> 结论：**"校准后 0.3 ppm"不能单独引用**；必须写"有限样本 0.64 ppm；out-of-sample 1.87 ppm（未达 ±1.5 目标）"。

| 项 | 10-seed 结果 | 旧图（2 seeds） | 处置 |

| skew 0.5→2 ps @2 MHz | **−1.44 dB [−1.73, −1.14]** | −2.0 dB | 用 −1.4 dB；旧图作废 |
| gain 10→50 ppm | **−5.58 dB [−6.11, −5.06]** | −5.0 dB | 用 −5.6 dB；旧图作废 |

两者 10/10 为负，方向确定；幅度是 stress 假设（2 ps / 50 ppm），不是封装实测。

## 7. X1 跨实现：INL 差 2.64×，先别引用

| 实现 | 条件 | INL 峰值 |
|:---|:---|:---|
| `model/charge_model` | σu=0.2%，seed=7，差分互补，8 片平均 | **16.4 ppm** |
| `behavioral` smoke_ramp | σu=0.2%，seed=7，profile=ideal | **43.3 ppm** |

- 比值 **2.64×**。两边都声称 3 unary + 7 binary、1024 单位、差分互补。
- 根因候选（未证实）：
  1. `model` 把 8 片的顶板电压**先各自归一化再平均**（`v = (vp−vn)/ACTIVE`），`behavioral` 可能是单阵列 1024 单位直接求解；
  2. 失配分配：`model` 每片 128 个独立电容；`behavioral` 可能按 P/N 两侧独立抽，或包含 termination 的固定 VCM；
  3. `behavioral` 的 ramp 是 4096 点、每码 4 点平均，端点/拟合口径不同。
- **处置**：在 X1 解决前，INL 只能引用"同一实现内"的开/关对比（16.4→0.64），**不能把 16.4 ppm 写成绝对 INL**。

## 9. 复现

```bash
cd 20b10m
python3 -m model.crossval         # ~30 s，出 results.json + summary.csv
python3 -m model.figures_ssot     # 出 f2/f3/f5/f6（10 seeds，独立 seed 段）
```

判定阈值（写死在脚本里，改阈值必须改本报告）：
- 动态：CI 全正 → POSITIVE；全负 → NEGATIVE；跨 0 → INCONCLUSIVE。
- 校准：cal_max < raw_min → PASS；否则 CONDITIONAL。
- 跨实现：差异 >20% → DISCREPANT。

## 10. 不能声称（本轮新增）

1. 不能声称"8× 平均在硅上值 1.7 dB"——只验证了模型与解析式一致。
2. 不能声称"片级 shuffle 用 DR 换 SFDR"——DR 方向不稳。
3. 不能声称"校准后 0.3 ppm 达 20 bit"——out-of-sample 1.87 ppm，未达 ±1.5。
4. 不能声称"INL=16.4 ppm"——两套实现差 2.64×，先对齐口径。
5. 不能声称"DEM/dither 有效"——只有字生成，没有注入/扣除。
