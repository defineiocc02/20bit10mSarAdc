## 1. 结论（5 条）

1. **位账与二级位宽站得住**：20.5 = 10+11−2+1.5 只有 `10 + 11` 这一个配法能同时闭合 LSB2=19.07 µV、G=32、RE 输出 1.25 Vpp、22 bit 输出——D-02/D-04 确认可冻结。
2. **D-03 必须修正**：一池 1024 单位（8 片×128）恰好用满 2^10，"第 11 次判决"（`fine[0]`，权重 0.5 LSB1 = 13.5 fF）**在物理上不存在元件**，且被 `1'b0` 丢弃 → 既不提供分辨率也不提供冗余。删掉后 ΦC1 从 5 拍降 4 拍：按 `timing_detail` 的 3.0 ns/拍，5 拍 = 15.0 ns **正好吃满包络（零余量）**，4 拍留 3 ns。
3. **D-01 的"15 ns 复位窗"是错的**：CT2 两相之间真实间隔 **60 ns**（A ΦC2 止 90，B ΦC2 起 150）。15 ns 是 A 帧尾到 B 帧头的 guard，属于**参考 buffer**，不是 CT2。单套 CT2 风险从"中"降为"低"，A1 可提前关闭。
4. **D-09 装得下，但草案的问法错了**：ΦC2 包络是 **40 ns**（cnt 10–17）不是 37.5；19 拍×2 = 38 ns，占用 **95%**，是全芯片最紧的一段。它同时是 D-04 的判据（12 bit → 20 拍 = 40 ns，零余量）。而 37.5/7.5 不是 5 ns 整数倍，20 tick 制根本装不出。
5. **噪声预算没有余量，且②段已超 0.25 dB**：26.5 µV 是**论文实测值**反推的四段分配，不是可以随便重排的设计预算；②（RA 放大相）是唯一有自由度的项。20.5 bit 对应 **ENOB 16.7 bit**，"20.5 bit"是字长口径。
6. **（追加）G 由 C_FB = 864 fF 定，不是 C_INC**：G = 27.648 pF/864 fF = 1024 单位/32 单位 = **32.000**（同一 unitcap 的整数比）。layout 反解的 27.68 把 C_INC 当成了增益元件；C_INC 改 **0.864 pF（32 单位）**后，`MANIFEST` §0 的 unitcap 规则才成立（1 pF = 37.04 单位本来就违规）。**改这一项不动噪声预算、不动位账**，只动节点电压与 W2 系数。
7. **（追加）126 个逐片系数"可辨识"，不需要单开片校准模式**——因为片→位置映射与每片码都是数字自己产生的；但前提是 `SliceSched` 导出**有序 8 片 ID 并在采样沿冻结**（现有 RTL 没有）。校到 10 ppm 后 8 片求和的剩余增益抖动 **3.5 ppm = 17 µV = 2.6 LSB_total**；不校则是 **31 ppm = 155 µV = 23 LSB_total**。这就是 144 系数买到的全部东西。
8. **（追加）封装与 die 互斥**：48 pad @150 µm ⇒ die ≥2000 µm（4 mm²），与"die 1.06"不可能同时成立。改 pad 40×40/pitch 76–80 µm 后 die 1.31–1.60 可行，但装配需封装厂确认。**退 32 脚不丢带宽**：24 bit/100 ns = 240 Mbit/s，单条 DDR lane 就够。
