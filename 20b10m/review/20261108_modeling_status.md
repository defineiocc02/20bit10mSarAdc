## 1. 四项数字技术的实现状态

### 1.1 总表

| 技术 | 代码里有吗 | 在哪 | 是什么形态 | 实测效果 | 主要局限 |
|:---|:---:|:---|:---|:---|:---|
| **LMS / 校准** | ✅ | `charge_model.py:128` `cal_residual()`<br>`charge_model.py:94-110` 特征投影 | **离线最小二乘（`np.linalg.lstsq`）**，一次性闭式求解，**不是迭代 LMS/NLMS** | INL 16.40 → **≤0.29 ppm**（n_avg=64） | ①不是自适应；②残差与 σu 无关；③没有独立留出集 |
| **DEM** | ❌ | — | **不存在**。`adc.py` 的 `shuffle` 只是"从 18 片随机选 8 片"，属片间选择，不是电容级 DEM | 无法测 | 片间洗牌已被版图证伪（66 ppmFS ≈ 98–138 LSB_total） |
| **dither** | ❌ | — | **全目录 0 处**（`grep -ri dither --include=*.py --include=*.sv` 无命中，只在 8 个 `.md` 里被提及） | 无法测 | 无发生器、无注入点、无去扰通路 |
| **CAAZ** | ⚠️ 仅行为级 | `adc.py:76-89` | 参数化模型：偶 +s / 奇 −s，共享 AZ 用 `az_share∈[0,1]` 控制 | +3.59 dB DR，其中**独家 0.58 dB** | 无 RTL；无 AZ 存储电容；无保持误差模型（`az_share` 是理想权重） |

### 1.2 LMS：它是"最小二乘"，不是"LMS"

这个术语必须改。两者差别对片上实现有实质影响：

| | 我们做的（`lstsq`） | 真正的 LMS/NLMS |
|:---|:---|:---|
| 求解方式 | 一次性闭式解 `w = (BᵀB)⁻¹Bᵀy` | 逐样本迭代 `w ← w + μ·e·x` |
| 需要什么 | 完整码表（1024 点）+ 每点多次平均 | 只需要逐样本流 |
| 收敛 | 无收敛过程 | 有步长 μ、收敛速度、稳态失调 |
| 适用场景 | **片外训练**（我们和 task1 都是这条） | 片上自适应 |

**我们的实际方案是"片外 lstsq 训练 + 片内冻结查表"**，与 `task1/README.md` 的"当前 LMS／NLMS 是**片外 Python 训练与行为验证**"一致。所以术语应统一为**"离线最小二乘校准"**，避免读者以为是片上自适应。

**已知的方法论缺陷**（T05 已指出，本文确认）：

```
cal_residual 的残差 = 特征空间对测量噪声的投影 ∝ sigma_meas / sqrt(n_avg)
```

实跑验证（`python3 -m model.charge_model`）：

| n_avg | 残差峰值 |
|:---:|:---:|
| 1 | 2.30 ppm |
| 16 | 0.57 ppm |
| 64 | **0.29 ppm** |
| 256 | 0.14 ppm |
| 4096 | 0.04 ppm |

**这条曲线完全由 1/√n 决定，与电容失配无关。** 而 `dac1_curves()['inl_cal']`（特征投影后的数学残差）是 **1.5e-10 ppm**——即"65 个特征能完全张成 16.4 ppm 的 INL"。

**结论**：我们**没有**"失配校准残差"这个概念，只有"测量精度限制"。真实残差应该由三部分组成，目前只算了第一项：

| 残差来源 | 现状 |
|:---|:---|
| ① 特征张成不完备（非位权项） | `charge_model` 里被假设为 0 |
| ② 测量噪声投影 | ✅ 已算（0.29 ppm @ n=64） |
| ③ σu 随时间/温度漂移 | ❌ 无模型 |

### 1.3 DEM：我们从来没有实现过

`adc.py:58-74` 的 `shuffle` 逻辑：

```python
if cfg["shuffle"]:
    idx = rng.choice(cfg["n_slices"], P.active, replace=False)   # 从 18 片随机选 8
else:
    start = (k * P.active) % cfg["n_slices"]                     # 固定轮转
```

**这是"哪 8 片参与本次转换"的选择，不是"片内 128 个单位电容轮转"。** 两者是不同层次：

| 层次 | 机制 | 我们的状态 | task1 的状态 |
|:---|:---|:---|:---|
| **片间**（18 片选 8） | 选片随机化 | 有模型，**已被版图证伪**（66 ppmFS） | 有（`slice_scheduler`） |
| **片内**（每片 128 单位） | Fig.11 DEM：15 个 2C + 16 个 1C 轮转 | **完全没有** | 有（`fig11_dem.sv`） |

**BL-v3 取消的是"片间洗牌"，片内 DEM 从未评估过**——这是一个空白，不是"已否决"。

### 1.4 dither：零实现

全目录检索确认：`.py` 与 `.sv` 中 **0 处**出现 `dither`。8 个 `.md` 里提到它，都是"计划"或"待定"。

无法评估效果，只能引用 task2 的实测（其口径与我们不同，仅作参考）：

| task2 实测 | 值 |
|:---|:---|
| 零宽码 | 678,189 → **0** |
| DNL 范围 | [−1.00, +4.12] → [−0.25, +0.28] LSB20 |
| SFDR | 127.265 → 128.554 dBc **和** 128.253 → 127.126 dBc（**有一项退化**） |
| SNDR | **不改善**（104.57 → 104.36） |
| 满幅代价 | 拒掉 **0.86%** 输入范围 |

### 1.5 CAAZ：行为级可用，但速率是硬约束

`adc.py` 的 CAAZ 是**输入折算的噪声模型**，不是电路模型。实跑（T05 数据 + 本次复核）：

| 指标 | 值 |
|:---|:---|
| DR 提升 | +3.59 dB（10 seeds） |
| 其中"AZ 抵消"独家 | **0.58 dB** |
| 其余 3 dB | 就是两点平均（与 CAAZ 无关） |
| 速率代价 | **10 → 5 MS/s**（每两笔出一个） |

**与我们 10 MS/s 的目标直接冲突**：2 相交织每相 5 MS/s，再做偶奇配对 → 每相 2.5 MS/s → 合计 5 MS/s。所以 CAAZ 在 BL-v3 里只能是诊断模式或 P2 备选。

### 2.4 覆盖率的量化结论

| 类别 | 有 | 部分 | 无 |
|:---|:---:|:---:|:---:|
| 噪声（7 项） | 5 | 1 | 1 |
| 失配（5 项） | 2 | 2 | 1 |
| 动态（9 项） | 1 | 0 | **8** |

**一句话**：**噪声与静态失配覆盖较好（12/21），动态效应几乎全缺（8/9）。**

这解释了为什么模型能给出可信的 **DR**（噪声决定），但给不出可信的 **SNDR**（失真与建立决定）——实测 SNDR − DR = 0.03 dB，即模型里失真项为零。

## 3. 批判性继承：前版（20b10mtask）的可取与不足

### 3.1 它做对的四件事（应当继承）

| # | 做法 | 为什么值得继承 | 我们的状态 |
|:--|:---|:---|:---|
| 1 | **同一颗虚拟芯片、开关并排对比** | 所有实验固定 seed，A/B 只差一个开关，结论可归因 | **刚补**（`plots_compare.py` 三张图） |
| 2 | **训练/留出分离，不用 DEM 激励训练的系数冒充无 DEM 基线** | 防"校准作弊"，这是最容易被忽略的纪律 | ❌ 我们没做 |
| 3 | **负结果照实写**（dither 有一项 SFDR 退化、DEM 让 SNDR 掉 2.96 dB、CAAZ 只值 1.3 dB 而非 4.3 dB） | 让后来的人不会重复踩坑 | ✅ 我们做到了（AUDIT.md） |
| 4 | **`slice_scheduler` 的 eligible/stall/有序 ID** | 我们没有这一层，且它顺手能解 D42 | ❌ 待借（约 20 行） |

### 3.2 它不能照搬的三件事

| # | 它的做法 | 为什么不适用于我们 |
|:--|:---|:---|
| 1 | **宽余差窗口（±100 mV）+ 粗步长（5.12 LSB20）+ dither 补码密度** | 它的 20 bit 是"字长 20、物理 17.6"，靠统计填码；BL-v3 是"物理 20.0、每码真实台阶"。**给一个本来就有台阶的 DAC 加 dither，是在解决不存在的问题** |
| 2 | **9 bit 一级 + 理想 12 bit ADC2** | 我们一级 10 判决、二级是真实 CT（C_INC + replica + 8×） |
| 3 | **CAAZ 作为主线** | 它把 10 → 5 MS/s；我们的 10 MS/s 靠 2 相交织，再叠 CAAZ 会掉到 5 MS/s |

### 3.3 根本分歧：两个"20 位"不是一回事

| | 前版（20b10mtask） | BL-v3 |
|:---|:---|:---|
| 输出字长 | 20 bit | 20 bit |
| DAC2 步长 | 48.83 µV = **5.12 LSB20** | 9.5367 µV = **1.00 LSB20** |
| 物理分辨率 | **17.64 bit** | **20.00 bit** |
| 零宽码 | 802,491 / 1,048,576（76.5%） | 0 |
| 靠什么填码 | dither + 8× 平均 + LMS | 不需要（每码有台阶） |
| 余差窗口 | ±5.12 LSB1（±100 mV） | ±2 LSB1（±19.5 mV） |
| 对校准的依赖 | 低（宽窗口容错） | **高（窗口窄，必须校准）** |

**这条分歧决定了 dither/DEM 的移植价值：前版必须做，我们可以不做。**

## 4. 本版本（BL-v3）相对 BL-v1/v2 的改进

| 项 | BL-v1 | BL-v2 | **BL-v3** |
|:---|:---|:---|:---|
| 码分辨率口径 | 19.00（+8× 折算 1.5 bit，口径混算） | 19.00（+0.28~0.67） | **20.00（纯 DAC 台阶）** |
| LSB2 / LSB_total | 19.07 / 19.07 µV（19 bit） | 同 | **9.5367 / 9.5367 µV（20 bit）** |
| DAC2 | 11 bit | 11 bit | **12 bit** |
| 相位切分 | 10/15/25/40 | 10/15/25/40 | **10/15/20/45（整 tick）** |
| ΦC2 余量 | −8.2 ns（误判）→ +0.8 ns | +0.8 ns（2%） | **+3.3 ns（7.3%）** |
| 洗牌 | 保留 | **取消**（版图证伪） | 取消 |
| 系数 | 25 / 64 / 144 三套并存 | 144/152 | **144/152/24 bit 偏差量** |
| 面积 | 0.689 / 1.06 | 0.934 / 1.41 | 同（DAC2 增量 0.001） |
| 文档一致性 | 4 套相位、5 套系数 | 收敛 | **单一裁定书** |

**改进的本质是三条**：
1. **口径去重**——不再用"平均折算位"充分辨率；
2. **单一权威**——`ARCH_DECISION_BLv3.md` 取代散落的 4 套相位/5 套系数；
3. **实证优先**——DR 与码宽解耦这一条是本次跑出来的，不是推的。

## 5. 后续必须补强的方向（按缺口大小排）

### P0：不补就无法声称 SNDR

| # | 缺什么 | 为什么是 P0 | 怎么补 |
|:--|:---|:---|:---|
| 1 | **DAC 建立（settling）** | `adc.py` 明写不含。而 SNDR − DR = 0.03 dB 说明失真项为零——**现在所有的 SNDR 数字都不可信** | 在 `simulate()` 里加一阶/二阶建立：`err = Σ ΔV_i·exp(−t_i/τ)`，τ 由 28 pF × R_on 给 |
| 2 | **参考 droop** | 69 pC / 300 pF = 230 mV（11.6 LSB1），是最大单项；模型完全没有 | 按码型积分电荷，一阶 RC 恢复 |
| 3 | **比较器亚稳态** | 高速下概率不可忽略，且会表现为"偶发错码"而非噪声 | 加 `P( metastable ) = exp(−t/τ_latch)` 的概率分支 |

### P1：影响结论可信度

| # | 缺什么 | 影响 |
|:--|:---|:---|
| 4 | **独立留出集** | 现在的 0.29 ppm 是在训练集上算的 |
| 5 | **σu 随温度漂移** | T05 的 B9(ii)：Δg(T) 极差 ≤40 ppm 只能硅测，模型至少要有温度系数 |
| 6 | **片内 DEM（电容级）** | 从未评估。前版实测"SFDR +6.3 dB 但 SNDR −2.96 dB"，要判值不值 |
| 7 | **Cmp1 失调与噪声分离** | 现在折在一起，无法分别定预算 |

### P2：可以做但不阻塞

| # | 缺什么 | 说明 |
|:--|:---|:---|
| 8 | dither | 我们的 LSB2 = 1 LSB20，零宽码问题本来轻 |
| 9 | 1/f 噪声 | 低频段（100 kHz）可能需要 |
| 10 | 开关电荷注入 / Ron 非线性 | 量级小，但 20 bit 下不能忽略 |

## 6. 一句话总结

**我们有的：噪声预算（5 项）、静态失配（2 项）、校准的最小二乘框架、CAAZ 行为模型。**
**我们没有的：所有动态效应（建立、带宽、增益、droop、亚稳态）、dither、电容级 DEM。**
**所以我们能算 DR（102.2 dB，可信）、不能算 SNDR（100.6 dB 里失真项为 0，不可信）。**

前版值得继承的是**实验纪律**（同芯片开关对比、训练留出分离、负结果照实写）和 **`slice_scheduler`**；不值得继承的是**宽窗口 + dither 那条路线**——那是为"17.6 位物理、20 位字长"服务的，我们的 20.0 位物理不需要它。

**下一步最该做的一件事**：把 settling 加进 `simulate()`。这是唯一一条"加了之后 SNDR 才有意义"的改动，也是 BL-v3 的 20 bit 能不能兑现的分水岭。
