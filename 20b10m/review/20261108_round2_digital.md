## 1. 8× tracking 第一次进「信号流级」

之前 8× 只存在于 v1 的加性噪声模型里。现在改成 v2 的「对同一余差读 M 次」：

```python
nz[0] = N(0, σ_ra)
nz[m] = ρ·nz[m-1] + N(0, σ_ra·√(1-ρ²))     # AR(1)：同一样本的 M 次读之间相关
w = [1,2,…,M/2,…,2,1] / Σw                  # 二阶 CoI 三角权
c2 = round( Σ w[m] · quantize(resid + nz[m]) )
```

### 实测（4096 点，100.1 kHz）

| 配置 | SNDR | Δ |
|:---|:---:|:---:|
| M=1（无重复） | 100.60 | — |
| M=2 | 101.23 | +0.62 |
| M=4 | 101.89（box）/ 101.75（tri） | +1.29 / +1.15 |
| **M=8** | **102.70（box）/ 102.46（tri）** | **+2.10 / +1.86** |

**三方对上了**：v2 信号流级 **+1.86**（tri）、v1 加性模型 **+1.71**、论文实测 **+1.9 dB**（p.56）。

这是第一次在「误差进判决域」的模型里算出 8× 的账，而不是把噪声平均一下。

### 一个反直觉的结果：均匀权比三角权好

M=8 时 **box（均匀权）+2.10 dB > tri（三角 CoI）+1.86 dB**，差 0.24 dB。

理论解释：AR(1) 正相关下，三角权把权重集中在中间几次读，而相邻读高度相关 → 有效独立样本数反而少；均匀权把权重摊平，等效更好。

**但这与论文用三角 CoI 的理由（噪声整形）不是同一件事**——论文的三角权是为了把噪声折叠带搬到 M·fs/2，那是频域行为，不是平均增益。**两者不能混为一谈，本条待验证**（需频域分析，当前模型给不出）。

### ρ 的敏感性（M=8, tri）

| ρ | Δ SNDR |
|:---:|:---:|
| 0.0 | +3.16 |
| 0.3 | +2.64 |
| **0.61** | **+1.86** |
| 0.8 | +1.17 |

ρ=0.61 是反解值不是实测（T05 早就指出），所以 **+1.86 这个数继承了这个不确定性**：ρ 若实测 0.3，收益会变 +2.64。

## 2. PRBS31 修好了

上一轮报告说「卡方 403.7，本实现待核对」。这轮定位到根因：**移位方向错了**。

| 实现 | 1 位比例 | 6 位字卡方（df=63，临界 99） |
|:---|:---:|:---:|
| 左移 + `x³¹+x²⁸`（原实现） | 0.4867（偏 12σ） | 403.7 |
| 右移 + taps 0x10000001 | — | 110.6 |
| 右移 + taps 0x40000001 | — | 101.7 |
| **右移 + taps 0x20000001** | **0.5034** | **68.7 ✓** |
| 右移 + taps 0x60000001 | — | **2.7×10⁶**（短周期陷阱） |

**关键教训**：`0x60000001` 的 1 位比例恰好是 0.5000（看起来对），但 6 位字卡方是 272 万——因为它让 LFSR 陷入短周期。**只验 1 位比例会漏掉这个坑，必须验字分布。**

## 3. CAAZ 重复乘 cos（UA1R2 参考包提示，我们同款缺陷）

`adc.py` 原实现：

```python
out = (xe - xo) / 2.0
out *= np.cos(np.pi*fin/(2*fs))     # <- 多余
```

配对平均的 sinc 响应**已经隐含在 `(xe-xo)/2` 里**（xe/xo 是相邻样本），再乘一次就是平方。

实测 2 MHz：幅比 **0.9045 = 0.951²**（配对本身 0.951）。

**影响面**：只影响**绝对增益标度**，不影响 DR/SNDR（信号与噪声同比例缩放）。修正后 DR 变化 <0.05 dB：

| fin | 无 CAAZ | 有 CAAZ | Δ |
|:---|:---:|:---:|:---:|
| 100.1 kHz | 102.01 | 105.62 | **+3.61** |
| 2000.1 kHz | 101.99 | 105.17 | **+3.18** |

已删除该行并注明出处（UA1R2 `REPORT_zh.md` §4.3）。

## 4. UA1R2 参考包：口径差异与可吸收项

`SAR20_10M_UA1R2_reference5094b2e_20261108.zip` 是**同一项目的另一条候选口径**，不是我们的分支。

### 4.1 口径对比（不能混用）

| 项 | UA1R2 | **BL-v3（我们）** |
|:---|:---|:---|
| 一级 | 10 bit DT，LSB1 = 9.765625 mV | **同** ✓ |
| 二级 | **11 bit CT2**，步进 19.073 µV | **12 bit**，步进 9.5367 µV |
| 位账标签 | 20.5 名义（6.743 µV 标称步进） | **20.00（纯 DAC 台阶）** |
| 传输码 | 22 bit offset binary，1 码 = 2.384 µV | 同 22 bit，但 LSB_total 不同 |
| RA | 32× | 32× ✓ |
| TA8 | 同笔内重复 | 同 ✓ |

**它保留 11 bit CT2 + 20.5 名义，我们选了 12 bit CT2 + 20.00。两条都能自洽，但数字不能互引。**

### 4.2 值得吸收的四条

| # | UA1R2 的发现 | 我们的状态 |
|:--|:---|:---|
| 1 | **CAAZ 重复乘 cos** | ✅ 本轮已修（同款缺陷） |
| 2 | **采样开关与参考开关同时导通的译码冲突**（模拟） | ⚠️ 我们没查过，应由模拟域核 |
| 3 | **旧 `base+8 mod 18` 轮转让同一片间隔在 200/300 ns 之间跳** | ✅ 我们的 `slice_schedule` 是 16 片两两交替，间隔均匀 |
| 4 | **`PHI_AZ` 与 RA 窗口重叠** | ✅ 我们 AZ 在 ΦC1 内，不重叠 |
| 5 | **U3B7 物理命令候选**：码 `c=128H+L`，H 片全选 128C、1 片 7 bit 细分；**要求原固定接 VCM 的第 8 个 1C 改成可切换** | 📌 若我们要做 1024 码的 3+7，这是唯一具体方案；但改的是模拟结构，需授权 |

### 4.3 它的两条「不要做」

- **不要给 22 位传输码因 "20.5 位" 额外乘 1/√2** —— 这与 T05 说的「缺 1/√2 增益抽头」相反。**两方冲突，未裁决**：T05 认为 22 bit 字装 1.414 FS 是有意设计，UA1R2 认为那是错的。**在拿到 DAC1 真实权重表之前，两说都不能采信。**
- **不要沿用「每 5 ns 一次判决」的同步状态机** —— 与我们在 BL-v3 定的「包络 + 自定时」一致 ✓

## 5. 还没实现 / 还没解决的

| 项 | 状态 | 卡在哪 |
|:---|:---|:---|
| **片内 DEM**（Fig.11 电容级轮转） | ❌ 未实现 | 需要 `charge_model` 支持逐单位的动态重分配，且要判「SFDR 收益 vs SNDR 损失」 |
| **1/G 增益校准** | ❌ 未实现 | 与 dither/DEM 同属「校准族」，但我们已有 144 系数覆盖 |
| **位重组最终式** | ⚠️ 名义式已给 | T05 与 UA1R2 对「是否乘 1/√2」有冲突，未裁决 |
| **PRBS 硬件移植** | ✅ 算法对 | 若要写 RTL，用 taps 0x20000001 + 右移 |
| **droop 样本内波形** | ❌ 仍是样本级 | 决定「300 pF + 预充够不够」，需逐切换求值 |

**下一步优先级**：droop 样本内波形 > 片内 DEM > 1/G。

理由：droop 是当前唯一能把 SNDR 从 100 dB 拉到 27 dB 的项，而片内 DEM 的收益（前版实测 +6.3 dB SFDR / −2.96 dB SNDR）在我们架构下未证实。
