# 信号流级模型 v2（2026-11-08）

> 目的：让非理想效应进入**判决域**，从而能算 SNDR（v1 只算得出 DR）。
> 代码：`model/simulate_v2.py`（约 160 行）；对照：`model/adc.py`（v1，保留不动）。
> 范围：只到行为级，不含 RTL。

---

## 1. v1 与 v2 的根本区别

```
v1:  out = quantize(vin + Σ加性误差)      → 误差只降 SNR，不产生失真
v2:  code = SAR(vin + 判决域内的误差)      → 误差改变判决，产生 INL/DNL/谐波
```

这就是为什么 v1 的 **SNDR − DR = 0.03 dB**（失真项为零），而 v2 能给出有意义的 SNDR。

**v2 的结构**：逐样本 → 一级 10 判决（逐位，含建立与 droop）→ 余差 → RA（有限增益/带宽）→ 二级 12 判决 → 标准两级冗余重组。参考 droop 是**跨样本状态**（一阶 RC）。

## 2. 三个交叉验证（模型自洽性）

| # | 校验 | 结果 | 判据 |
|:--|:---|:---|:---|
| 1 | 理想（无噪声、无效应） | **SNDR 122.14 dB**，码误差 **2.68 µV** | 应 = LSB_total/√12 = 9.5367/3.464 = **2.75 µV** ✓ |
| 2 | 只加热噪声 | **SNDR 100.65 dB** | v1 同条件是 **100.59 dB** ✓ 两套模型互证 |
| 3 | 单点 SAR | x=6.3934 V → c1=**654**（应 655），v_dac=6.3867 | 误差 ≤1 LSB1 ✓ |

第 1 条最重要：**理想极限 122 dB 是 v2 的锚点**。没有这个锚点，模型错在哪一层看不出来。

## 3. 四项非理想的设计边界（实跑）

| 效应 | 扫描 | 拐点 | 结论 |
|:---|:---|:---|:---|
| **DAC 建立** | τ = 0.1 → 2 ns | **τ ≤ 1 ns 完全无影响；τ = 2 ns 崩到 45.7 dB** | τ/t_bit ≤ 1/3；即 ΦC1 每次 3 ns 内必须建立到 5τ |
| **参考 droop** | C_decap = 100 pF → 10 nF | **300 pF → 65.3 dB；3 nF → 100.65 dB（回到基线）** | 片上去耦需 **≥3 nF**；而 1 nF 片上已不可行（0.426 mm²）⇒ **必须靠 DynRefBuf 预充拆分，不能靠加大电容** |
| **RA 有限增益** | A0 = 30 → 70 dB | **50 dB → 100.29；40 dB → 98.02** | A0 ≥ **50 dB** |
| **亚稳态** | t/τ_latch = 1 → 20 | 2048 点内 **>2 LSB 的坏点全为 0** | 本抽样规模测不出；需 1e6 点或更小 t/τ。**不能用 SNDR 判，要看坏点数** |

**四条边界里最硬的是 droop**：仿真说 3 nF 才够，而物理上 1 nF 都放不下 → **这条只能靠电路结构（粗充/精充拆分）解决，不能靠电容**。这与 T02 代理的判断一致。

## 4. 我在实现中踩的四个坑（记录，避免重犯）

信号流级模型比"输入折算"难写得多，每个环节都能错，而且错了不一定报错——只会给出一个错的 SNDR。

| # | Bug | 症状 | 根因 |
|:--|:---|:---|:---|
| 1 | SAR 位序反了 | 码误差 2.58 V | 权重是 `LSB1·2^(N−1−b)`，但写码用了 `1<<b` |
| 2 | 双极性输入没平移 | 负半周全判 0 | SAR 从 0 向上逼近，只适用 [0, FS] |
| 3 | 窗口归一化多乘 G | 理想只有 60 dB | 余差与窗口都在"折输入"域，G 只影响 RA 输出摆幅 |
| 4 | 偏移二进制缺偏置 | `& mask` 把负数变巨大正数 | 重构式 `c1·2^(N2−R)+(c2−2^(N2−1))` 本身已居中于 2^(N−1) |

**教训**：写这类模型必须**先有理想极限做锚点**（本例 122 dB / 2.75 µV），否则四个 bug 里任何一个都足以让结论错 60 dB 而看不出是 bug。

## 7. 按专利实现的两项机制（2026-11-08 补）

六篇专利/论文逐篇核过，其中两项直接对应我们 v2 里最大的缺口，已实现：

| 专利 | 机制 | 在 v2 里的实现 |
|:---|:---|:---|
| **US10826519B1**（Low Power Reference） | 内部参考**先预充**到接近外部电平，再切换 → 只补差额，建立快、取电少 | `ref_precharge=True`：droop 按 **Δcode** 算，而非按绝对码 |
| **US10707889B1**（Interleaving） | tracking 相位用另一路上一样本结果**预置 DAC**，跳过 reset → 输入电荷从 Q=A·CIN 变成 ΔQ | `pretrack=True`：droop 按 \|code−prev_code\| 算 |

### 实测效果（C_decap = 300 pF）

| 配置 | 103 kHz | 2002 kHz |
|:---|:---:|:---:|
| 无 droop（基线） | 100.65 dB | 100.67 dB |
| droop 全额（从 0 起） | **27.06 dB**（−73.6） | **30.98 dB**（−69.7） |
| + 参考预充 [14] | **56.59 dB**（改善 **+29.5**） | 34.40 dB（+3.4） |
| + 预置 tracking [12] | 56.59 dB（与上同） | 34.40 dB（与上同） |

### 怎么读这三个数

1. **droop 全额是灾难**：1024 单位 × 27 fF × 5 V = **138 pC**，落在 300 pF 上 = **460 mV**（9.2% 参考误差）→ SNDR 只剩 27 dB。这解释了为什么 T02 说"没有 DynRefBuf 就崩"。
2. **预充把它压了 50 倍**：103 kHz 时相邻码差平均只有 20（满量程的 1/51），电荷从 138 pC 降到 2.7 pC，droop 从 460 mV 降到 **9 mV**。
3. **但仍不够**：要 droop < 2.4 mV（0.25 LSB1）需要 Δcode ≤ 5，而 103 kHz 时实际是 20，差 4 倍。
4. **2 MHz 时预充救不了**：相邻码差平均 368（满量程的 1/2.8），省不下电荷 → 只改善 3.4 dB。**这是"预置只对慢信号有效"的定量证据**，与 [12] 的适用条件一致。

### 这里必须说明的模型高估

我的 droop 模型是**保守的**：把"上一样本结束时的 droop"当成本样本全过程的参考误差。实际 droop 是转换过程中逐渐恢复的波形，比较发生在其间某一时刻，真实影响小于此。

所以「300 pF + 预充 = 56.6 dB」应读作**下界**，不是定论。要拿到可信的数，需要把 droop 建成**样本内的波形**（每次切换后按 t 求值），而不是样本级状态。

### 六篇专利的归属判定

| 专利 | 技术 | 对 BL-v3 是否适用 |
|:---|:---|:---|
| [11] DEM（片内子段洗牌） | 16C/8C/4C/2C/C 各带开关轮转 | ⚠️ 可选。前版实测"SFDR +6.3 dB 但 SNDR −2.96 dB" |
