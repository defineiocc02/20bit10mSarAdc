# 架构推荐与数字接口定义

> 结论先给：**走 CICC 主线（11 b + CT 二级），借 ADI 的交织骨架，数字侧用"相位包络 + 自定时"接口。**
> 本文定 L2（数字内部）接口；L0/L1 见 `ANALOG_DIGITAL_IF.md`。

---

## 1. 推荐架构

```
                    ┌─────────────── 数字（1.8 V）────────────────┐
CLK ───────────────►│ PhaseGen  20 tick × 5 ns，出相位包络         │
RSTN ──────────────►│   │                                          │
                    │   ├─► SliceSched   18/8/2，出 SLICE_ID/MASK  │
                    │   ├─► Sar1Ctrl     11 b（6 flash + 5 SAR）   │
                    │   ├─► Sar2Ctrl     12 b + 8× repeat          │
                    │   ├─► Mapper/DEM/Dither                      │
                    │   ├─► SINC2 → Recombine → LMS                │
                    │   └─► RegFile（配置/状态）                    │
                    └──────┬───────────────────────▲──────────────┘
              相位/码/选片 │                       │ 判决/eligible/fault
                    ┌──────▼───────────────────────┴──────────────┐
                    │ 模拟：SW → DAC1(18片) → CMP1 → RA → C_INC/DAC2 → CMP2 │
                    └──────────────────────────────────────────────┘
```

| 决策 | 选择 | 理由 |
|:---|:---|:---|
| 一级位数 | **10 b（4 flash + 2 SAR + 4 fine）** | BL-v3 A2；电容仍是 3 unary + 7 binary |
| 二级 | **CT + C_INC + replica + 8× + SINC2** | 论文的全部创新，丢了就没必要做这颗 |
| 交织 | **2 相，18 片池（8+8+2）** | 达到 10 MS/s 且不恶化驱动 |
| 时钟 | **200 MHz 主时钟，5 ns tick，20 tick** | 五相位可整除：2/3/4/9/2 |
| ΦC2 内部 | **自定时（2.25 ns/拍）** | 20×2.25 ns = 45 ns；主时钟给不了 444 MHz |

**被否的两个方案**

| 方案 | 为什么否 |
|:---|:---|
| 全 ADI（9 b + 12 b ADC2） | 数字现成（20b10m 分支已 GDS），但丢掉 CT 二级/重复/平均，不再是论文复现 |
| CICC 原样（5 MS/s 单路） | 没有交织，达不到 10 MS/s |

> Plan B：若 CT 二级做不出来，退回"9 b SADC + 12 b ADC2 + 交织"，直接复用 20b10m 分支的数字与后端。这条要留着，但不在主线上。

## 2. 数字接口分四层

| 层 | 边界 | 内容 | 谁定 |
|:---|:---|:---|:---|
| **L0** | 芯片引脚 | VIN/VREF/CLK/DOUT/RDY/CAL | 系统 |
| **L1** | 模拟↔数字宏 | 38 条：相位/握手/码/比较器/故障 | 已出 v0.9（`ANALOG_DIGITAL_IF.md`） |
| **L2** | 数字内部模块 | 本文 §3 | 数字组 |
| **L3** | 配置/状态 | SPI 或并行寄存器、校准系数、状态回读 | 数字组 |

## 3. L2 模块接口

| 模块 | 输入 | 输出 | 时钟域 | 延迟约束 |
|:---|:---|:---|:---|:---|
| `PhaseGen` | CLK, RSTN | `PHI_S/C0/C1/RA/C2[1:0]`、`PHI_AZ`、`EN_RA`、`HOLD[1:0]`、`TICK[4:0]` | 200 MHz | 边沿偏斜 ≤200 ps |
| `SliceSched` | `ELIGIBLE[17:0]`, TICK | `SLICE_ID[7:0][4:0]`, `SEL_VALID`, `STALL` | 200 MHz | 周期开始前 0.5 ns 稳定 |
| `Sar1Ctrl` | `PHI_C0/C1[b]`, `CMP1_P/N[b]`, TICK | `D1[9:0]`, `CMP1_CLK[b]`, `DONE1`, `FAULT_TO1` | 相位包络内自定时 | 6 拍 ≤10 ns + 4 拍 ≤15 ns |
| `Sar2Ctrl` | `PHI_C2[b]`, `CMP2_P/N[b]` | `D2[11:0]`, `DT[7:0]`, `CMP2_CLK[b]`, `DONE2` | 自定时 | 20 拍 ≤45 ns |
| `Mapper` | `D1[9:0]`, `SLICE_ID`, `DEM_SEL` | `D1_MASK[125:0]`（18 片 × 7 bit） | 200 MHz | 相位首 tick 前 |
| `DemDither` | `SEED[7:0]`, `CAL_EN` | `DEM_SEL[2:0]`, `DITHER[5:0]` | 200 MHz | 1 ns 内完成洗牌 |
| `Sinc2` | `DT[7:0]` | `DO3[23:0]` | 200 MHz | M=8，位宽 ≥26 |
| `Recombine` | `D1[9:0]`, `D2[11:0]`, `DO3`, `W2[15:0]` | `DOUT[21:0]` | 200 MHz | 2 拍内 |
| `Lms` | `ERR[11:0]`, `CAL_EN` | `COEF[15:0]` | 200 MHz | 一次性，非实时 |

### 3.1 关键决策：相位包络 + 自定时

ΦC2 要 20 拍 × 2.25 ns = **444 MHz 等效**，主时钟只有 200 MHz。三条路：

| 方案 | 可行性 | 结论 |
|:---|:---|:---|
| 全局 500 MHz | 180 nm STA 压力大、功耗高 | ✗ |
| PLL/DLL 倍频 | 多一个宏、抖动进采样沿 | ✗ |
| **包络 + 自定时** | 论文原设计就是异步 SAR | ✓ |

接口定义：

```
PHI_C2[b] ↑ ──► Sar2Ctrl 启动
                │  每拍：拉 CMP2_CLK → 等 CMP ready → 更新 D2/DT → 下一拍
                │  20 拍走完 → DONE2 ↑
PHI_C2[b] ↓ ──► 包络结束；若 DONE2 未到 → FAULT_TO2，本样本打 flag
```

- **数字只负责包络的起止与超时计数**，位与位之间不等主时钟；
- `TICK[4:0]` 只用来对齐相位边界和调度，不参与位判决；
- 超时保护必须真做：卡住的比较器不能把整个 bank 拖死。

同样的方式适用于 ΦC0（6 次）与 ΦC1（4 次）：包络 10 ns / 15 ns，内部自定时。

## 4. 数据格式

| 信号 | 宽度 | 编码 | 说明 |
|:---|:---:|:---|:---|
| `D1[9:0]` | 10 | 偏移二进制 | 一级码：`D1=128·k+b`，k=D1[9:7]，b=D1[6:0] |
| `D1_MASK[125:0]` | 126 | 18 × 7 bit | 物理片 i 的码在 `bit[7i+6:7i]`；SSOT #28 |
| `D2[11:0]` | 12 | 偏移二进制 | 二级码；`D2=2048` 为零余差 |
| `DT[7:0]` | 8 | 二进制累加 | 8× 重复码 |
| `DO3[23:0]` | 24 | 有符号 | SINC2 输出，Q 格式待定 |
| `DAC1_MASK` | — | 同 `D1_MASK` | 旧名，已合并 |
| `DOUT[21:0]` | 22 | 偏移二进制 | 最低位 = 0.25 LSB20（1 LSB_total） |

重组公式（总 LSB 为单位）：

```
DOUT_code = 2^21 + (D1 − 512) × 1024 + (D2 − 2048)   // 1 LSB_total = 1 码
          = 2^21 + ((D1 − 512) << 12) + ((D2 − 2048) << 2) // 22 bit，LSB_xfer = 0.25 LSB_total
```

> 实际用 Q 格式权重，`W2[15:0]` 由 LMS 训练后冻结；上式为名义值。

## 5. 数字侧时序预算（200 MHz，5 ns tick）

| tick | 相位 | 数字动作 |
|:---:|:---|:---|
| 0–1 | ΦC0 | 启动 Sar1Ctrl（6 拍自定时），出 D1[9:4] |
| 2–4 | ΦC1 | 继续 4 拍自定时，出 D1[3:0]，出 DONE1 |
| 5–8 | ΦRA | 数字空闲；准备 DAC2 预置码 |
| 9–17 | ΦC2 | 启动 Sar2Ctrl（20 拍自定时），收 D2/DT |
| 18–19 | guard | SINC2、重组、切片交换、更新 ELIGIBLE |

数字关键路径：`ΦC2 结束 → SINC2(8 点) → 重组 → DOUT` 要在 10 ns 内完成；不够就流水一拍。

## 6. 风险

| 风险 | 影响 | 缓解 |
|:---|:---|:---|
| 自定时超包络 | 样本错、bank 卡死 | 超时计数器 + FAULT flag，包络强制关断 |
| 2.25 ns 比较器 ready 路径 | 444 MHz 级延迟 | 比较器输出就近锁存，数字只收已同步的判决 |
| `D1_MASK` 位宽未定 | **已解决**：56 bit，见 SSOT #28 | — |
| DEM 1 ns 预算 | 洗牌做不完 | 提前一拍算，或在 ΦRA 期间预计算 |
| 200 MHz STA @180 nm | 时序不收敛 | 关键路径切到 100 MHz 双沿，或加流水 |

---

## 7. 冻结顺序

1. ~~`DAC1_MASK` 位宽与位序~~（已定，SSOT #28）；
2. `α` 与 `G`（已定：G=32、α=4 LSB1；见 SSOT #4/#18）；
3. 自定时的超时阈值（每个相位给多少 ns 余量）；
4. `DOUT` 位宽与 `0.5 LSB` 的表示（21 位还是 20 位截断）。

这四条定完，L2 就能冻结；其余可以边做边调。
