# 导入 Virtuoso 的步骤

> 目标：在 EDA 机器上把 `20b10m/` 变成真正的 OA 库 `CICC26_SAR`（26 个 cell，233 个引脚）。
> 全程不改任何电路，只建骨架。

## 0. 前置

| 项 | 要求 |
|:---|:---|
| Virtuoso | IC6.1.7 / IC23 均可 |
| PDK | smic18 + SP018WP（5 V IO）；tech library 名按实际填 |
| 存放 | 建议 `/home/<user>/work/20b10m/`，**不要放 NFS 慢盘** |

## 1. 拷贝

```sh
scp -r 20b10m <eda-host>:/home/<user>/work/
```

目标机上应能看到 `20b10m/verilog/20b10m_skeleton.v` 与 `20b10m/skill/create_lib.il`。

## 2. 建库

CIW 命令行：

```skill
load("/home/<user>/work/20b10m/skill/create_lib.il")
createCICC26Lib("/home/<user>/work/20b10m/cds")
```

挂了 PDK 的话：

```skill
createCICC26Lib("/home/<user>/work/20b10m/cds" "smic18")
```

预期输出：`已创建库 CICC26_SAR` + `新建单元：26 / 26`。

> 若 CIW 报 `ddCreateLib` 相关错误，先确认路径可写、磁盘有空间。

## 3. 生成引脚（关键一步）

菜单 **File → Import → Verilog…**

| 选项 | 填什么 |
|:---|:---|
| Netlist File | `20b10m/verilog/20b10m_skeleton.v` |
| Target Library | `CICC26_SAR` |
| Import Structure | 按 module 建 cell（不要 flatten） |
| Create schematic / symbol | 两个都勾 |
| Overwrite existing | 若第 2 步已建空 cell，这里选覆盖；或跳过第 2 步 |

导入后应生成 26 个 cell，每个都带 symbol 与引脚。

## 4. 核对引脚

按下面的数字逐个比（数值来自 `spec/interfaces.csv`）：

| cell | pins | cell | pins |
|:---|:--:|:---|:--:|
| Sar20bTop | 14 | Sar2Ct | 12 |
| Sar1Top | 19 | CincCouple | 9 |
| CoarseAdc6b | 9 | Dac2_12b | 7 |
| Dac1_11b | 14 | Dac2Replica | 7 |
| SwSample5v | 7 | Cmp2 | 7 |
| Cmp1 | 7 | SarLogic2 | 10 |
| SarLogic1 | 9 | DigitalTop | 10 |
| TriLevelDrv | 11 | LsbRepeat8 | 5 |
| RingAmp3 | 10 | Sinc2Dec | 5 |
| FiaA1 | 9 | GainScale | 5 |
| AmpA2 | 8 | BitRecombine | 6 |
| FiaA3 | 9 | LmsCal | 5 |
| BiasGen | 9 | RefBuffer | 10 |
| **合计** | | | **233** |

快速核对（在 CIW 里）：

```skill
foreach(c '("Sar20bTop" "Sar1Top" "RingAmp3" "Sar2Ct" "DigitalTop")
  printf("%s: %d pins\n" c length(ddGetObj("CICC26_SAR" c)->terminals))
)
```

若数字对不上，多半是 bus 被展开成了单 bit（`DOUT<20>` 拆成 21 个脚），
在 Verilog Import 选项里关掉 "Expand buses"。

## 5. 从 symbol 生成 schematic 骨架

Library Manager 里选中 26 个 cell → 右键 **New → Cell View… → schematic**（或对每个 cell 用
`schCreateWindow` 生成）。此时 schematic 为空、只有 14/19… 个 pin，正是要填的骨架。

## 6. 挂到 cds.lib

```sh
echo 'DEFINE CICC26_SAR /home/<user>/work/20b10m/cds' >> cds.lib
```

## 7. 打快照

```sh
cd /home/<user>/work
tar -czf 20b10m_G0_skeleton.tar.gz 20b10m/
sha256sum 20b10m_G0_skeleton.tar.gz
```

把 sha256 记进 `STATUS.md`。

## 8. 验收

- [ ] 26 个 cell 全部存在，schematic + symbol 两个 view 都有
- [ ] 引脚总数 233，逐个对得上表
- [ ] `Sar20bTop` 的 symbol 能放进一个新的 schematic 并正常显示
- [ ] 库能在 Library Manager 里展开，无红色警告

## 常见问题

| 现象 | 原因 | 处理 |
|:---|:---|:---|
| verilogIn 跳过已存在的 cell | 第 2 步建了空 cell | 先删空 cell，或选 Overwrite |
| 引脚数多出一倍 | bus 被展开 | 关掉 Expand buses |
| 电源脚丢失 | Verilog 优化 | 检查 `VDD5/VDD18/GND` 是否在 module 端口里 |
| 中文路径报错 | Virtuoso 对非 ASCII 路径敏感 | 目标机路径全用英文 |

## 9. 如果要把库名也改成 SAR20B10M

当前库名是 `CICC26_SAR`（指向论文），工程目录是 `20b10m`。要统一：

1. 改 `skill/create_lib.il` 里的 `libName = "CICC26_SAR"` → `"SAR20B10M"`；
2. 改 `cds.lib` 的 DEFINE 名称；
3. 重新执行第 2～3 步（库还没建过的话，直接改就行，无迁移成本）。

已建库之后再改，要走 Virtuoso 的 Library Manager rename，不要手工改目录名。
