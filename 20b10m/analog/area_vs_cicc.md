# 面积对标成电（同工艺 180 nm BCD）

> 成电 CICC 2026 原文 die photo：**core 0.53 mm² = 813 × 656 µm**，28 pF/侧，5 MS/s，3.57 mW。
> 我们的 10 MS/s 部分交织：**18 片/侧 = 62 pF/侧（2.25× 电容）**，RA/CT2/参考/数字单套。
> 结论：**core 不应是 3.2 mm²，而是 0.7–1.0 mm²；die 0.95–1.25 mm²。** 4 mm² 是“宽松版”，不是对标版。

## 1. 从成电版图反推密度

| 量 | 成电 | 说明 |
|:---|:---|:---|
| 单位电容 | 27 fF，3.7×3.7 µm | 27 fF / 13.7 µm² ≈ **2.0 fF/µm²** |
| DAC1 | 28 pF/侧 | 差分 56 pF → 净面积 28,000 µm² |
| core | 0.53 mm² | 813 × 656 |
| DAC1 在 die photo 中占比 | 约 0.065–0.09 mm² | 红框约 380×180 µm |

→ 同工艺、同单位电容下，**用 2 fF/µm² 算，不要用 1.2**。我们之前的 1.2 把 DAC 面积高估了 67%。

## 2. 我们的面积（对标算法）

| 项 | 成电 | 我们（10 MS/s 部分交织） | 说明 |
|:---|:---:|:---:|:---|
| DAC 电容 | 56 pF 差分 | **124 pF 差分（2.25×）** | 18 片/侧，8 用 + 8 采样 + 2 备 |
| DAC 面积 | 0.067 | **0.15** | 2 fF/µm² + 开关/自举/走线 |
| 粗量化 | 0.02（6b） | 0.028（4b+2b） | 15 cmp |
| SliceMux | — | **0.04** | 18:1 选 8 |
| RA | 0.02 | 0.02 | 单套 |
| CT2+DAC2 | 0.015 | 0.015 | 单套 |
| 参考 | 0.05 | 0.05 | 单套 |
| 数字 | 0.03 | 0.05 | 48 系数 |
| 去耦 | 0.05（估） | **0.13（300 pF）** | 若 1.0 nF → 0.43 |
| 走线/隔离 | ≈0.27 | ≈0.30 | |
| **core** | **0.53** | **0.70（300 pF）/ 1.00（1.0 nF）** | |
| **die（+100 µm pad ring）** | 0.73（估） | **0.95 / 1.25** | |

## 3. 结论

| 版本 | core | die | 用途 |
|:---|:---:|:---:|:---|
| **对标版（推荐）** | **0.70** | **≈0.95** | 300 pF 去耦，QFN-48 5×5，成本/面积与成电同量级 |
| 舒适版 | 1.00 | ≈1.25 | 1.0 nF 去耦，参考更稳 |
| 宽松版（之前的 4 mm²） | 3.2 | 3.96 | 只为“什么都放得下”，不是对标；不建议首硅 |

**推荐首硅做“对标版”**：core 0.70 / die 0.95，QFN-48 5×5 或 6×6；把省下的面积换成测试结构/备用 slice 即可，不必上 4 mm²。

## 4. 对 floorplan 的修正

- 成电版图：DAC1 在顶部（P/N 两块 28 pF），Coarse ADC 右上，RA 中央，DAC2+replica 在 RA 下，Logic 底部，pad 环四边。
- ADI 版图：RDAC 中央（竖条切片），Quantizer 左，RA/ADC2/Reference 右，Digital 左上。

- 尺寸从 2200×1800 收到 **约 1200×1000（die 1.2 mm²）**；4 mm² 图仅作“宽松版”参考。
