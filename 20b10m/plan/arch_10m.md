# 10 MS/s 立项架构（v1.0，2026-11-07）

> 目标：20.5 bit / **10 MS/s** / SNDR 99.4 dB@100 kHz / DR 102.5 dB / 180 nm BCD。
> 结论先行：**2 相时间交织（A/B 各 5 MS/s，相位差 100 ns），DAC1 拆 18 片池（8 转换 + 8 采样 + 2 备），RA / 6b flash / 参考 / 数字后端全部共享。** 单相帧仍是 90 ns，单相采样窗仍有 110 ns——**不靠倍频，靠"两个 5 MS/s 错开 100 ns"**。

---

## 1. 为什么不是倍频，也不是两套完整 ADC

| 路线 | 结果 | 判定 |
|:---|:---|:---|
| 直接倍频（周期 100 ns，单阵列） | ΦC2 37.5→18.75、ΦC0 7.5→3.75、ΦRA 25→12.5，三条同时崩；采样窗只剩 10 ns（论文要求 >100 ns） | ✗ 物理不成立 |
| 两套完整 ADC（各 28 pF + 各自 RA） | 面积 +0.10 mm²、RA 功耗 ×2（+797 µW），且两套 RA 的失调/增益失配要各自校准 | 可行但贵 |
| **2 相 + 18 片池 + 共享 RA** | 单相 90 ns 帧不变；RA 在 200 ns 内只用 50 ns（25 ns×2），可共享；flash/参考/数字同样错时共享 | **✓ 选定** |

**共享的物理前提**：A 相 ΦRA = 32.5–57.5 ns，B 相 ΦRA = 132.5–157.5 ns，**在 200 ns 周期内不重叠**；ΦC0、ΦC2 同理。所以"共享"不是分时复用抢时间，而是两个相位的占空比本来就互补。

---

## 2. 帧与相位（单相 200 ns 周期）

```
A: 采样 90–200 ──► 采样沿 200 ──► ΦC0 0–7.5 ──► ΦC1 7.5–22.5 ──► ΦRA 22.5–47.5 ──► ΦC2 47.5–85 ──► guard 85–90
B: 相位整体 +100 ns
输出：采样沿每 100 ns 一次 → 10 MS/s
```

| 相位 | A 相绝对时间 (ns) | B 相绝对时间 (ns) | 共享资源冲突？ |
|:---|:---:|:---:|:---|
| ΦS 采样沿 | 0 / 200 | 100 / 300 | 否（各自阵列） |
| ΦC0（6b flash） | 0–7.5 | 100–107.5 | 否（错开 100 ns） |
| ΦC1（5b 细搜索） | 7.5–22.5 | 107.5–122.5 | 否 |
| ΦRA（RA 放大） | 22.5–47.5 | 122.5–147.5 | **否 → RA 可共享** |
| ΦC2（11b + 8×） | 47.5–85 | 147.5–185 | 否（CT 二级各自独立） |
| guard | 85–90 | 185–190 | 否 |

> 注：上一版把 ΦRA 写成 25–50 ns 是笔误；以本表为准（ΦC0 7.5 + ΦC1 15 = 22.5 起）。

**采样窗**：A 相上一次转换结束在 85 ns，下一次采样沿在 200 ns → **跟踪 115 ns**；B 相同。满足论文 "sampling >100 ns"。

## 3. DAC1：18 片池，3+7 分段

- 单片 **3.456 pF** = 128 × 27 fF；一片内 **7 bit 二进制**（1…64，另 1 个 dummy）。
- 一个采样由 **8 片并联**组成 28 pF，**高 3 bit 用 8 片的温度计选择**（unary），低 7 bit 在片内二进制。
- 18 片 = 8（A 相）+ 8（B 相）+ 2 备用；`SliceShuffler` 每笔随机分配片到相位与 unary 位置 → 片间失配、片间 skew 被平均成噪声而不是杂散。
- 代价：DAC1 面积 0.068 → 0.153 mm²（×2.25）；收益：单片的 128 单位做 7 bit（匹配压力比 1023 单位做 10 bit 小），且 2 个备用片可救良率。
- 校准：LMS 系数从"10 位权 + 半组"改为"**每位权的 7 个二进制权 + 8 个 unary 片权 + 增益/失调**"，总数约 **34–38**，配置寄存器仍按 40 槽预留。

## 4. 时钟：外部 200 MHz，不用 PLL

| 项 | 方案 |
|:---|:---|
| 主时钟 | **外部 200 MHz 差分**（LVDS 或 AC 耦合正弦，0.8–1.2 Vpp），专用 `CLKP/CLKN` pad，片内 100 Ω 端接 |
| 分频 | 片内 ÷20 计数器 → 10 MHz 采样沿；A/B 由计数器 bit 选择，**相位差恒为 20 个 tick = 100 ns**（整数，无模拟延时） |
| 抖动 | 外部时钟 <100 fs；片内缓冲/分频 <0.3 ps；**验收 σ_t ≤1.0 ps，设计目标 0.5 ps** |
| 相位 skew | 两相 PHI_S 走对称树 + **无源 cap-trim（8 档 × 2 fF ≈ 0.5 ps/档）**，目标 <1.6 ps |
| 为什么不用 PLL | PLL 自身 jitter 0.3–1 ps，会直接吃掉 2 MHz 的 58% 误差预算；10 MS/s 只需要 200 MHz，外部给得起 |

**引脚**：`CLKP/CLKN` 各 1，独立 `VDD18_CLK`/`VSS_CLK` 可选（与 `VDDIO` 合并时需 ≥5 pF 去耦）。

## 5. 基准：外部 5 V + 2.5 V，片内只做缓冲与预充

| 基准 | 来源 | 片内处理 |
|:---|:---|:---|
| DAC1 高/低轨 | 外部 **5.000 V**（`VREF5`） | `RefBuffer`（5 V，R_out ≤20 Ω）+ 300 pF 去耦 + `DynRefBuf` 粗预充；两相共享 |
| DAC2 满量程 | 外部 **2.500 V**（`VREF2`） | 独立 2.5 V buffer（1 pF 负载，建立 <1 ns） |
| 共模 | 外部 **2.500 V**（`VCM`） | 直接做采样共模与 DAC1 复位轨；需要 ≥100 µF 板级 + 100 nF 片外 |
| 偏置 | 片内 `BiasGen` | 外部只给 `IREF`（10 µA）或电阻 |

**为什么 5 V 参考要外供**：980 µW 的参考功耗里，buffer 只占 400–500 µW；若片内做 5 V 低噪基准，需要 bandgap + LDO + 大去耦，面积极不划算，且噪声难压到 2.9 µV。**基准外供、片内只缓冲**是 20 bit 的常规做法。

## 7. 面积与功耗

> **2026-11-08 修正**：按 ISSCC 2024 9.8 的“部分交织”——**只交织 DAC1 的 18 片池，RA/CT2/量化器/参考/数字全部单套共享**。4 mm² 版面积与布局以 `analog/floorplan_4mm.md` 为准；下表是早期全通道估算，仅作对照。

### 早期全通道估算（作废，仅对照）

| 项 | 5 MS/s | 10 MS/s | 增量原因 |
|:---|:---:|:---:|:---|
| DAC1 | 0.068 | **0.13–0.26** | 18 片 × 3.456 pF = 62 pF/侧；MIM 1–2 fF/µm² 决定上限 |
| DAC2 + C_INC + replica | 0.012 | **0.024** | 两相各一套 CT 二级 |
| RA | 0.011 | **0.011** | **共享，不增** |
| 6b flash | 0.031 | **0.031** | 共享，不增 |
| 参考/去耦 | 0.155 | **0.160** | 峰值错开，去耦不翻倍 |
| 数字 | 0.060 | **0.068** | 两相调度 + 18 片 shuffle |
| 其他 | 0.017 | 0.017 | — |
| **核心** | **0.414** | **≈0.69**（1 fF/µm² MIM） | 按公开 MIM 密度重算；详见 `analog/area_model.md`；堆叠 2 fF/µm² 可到 0.62 |
| **die** | 0.66 | **≈1.06 / 36 pad** | core 830 + 2×100 pad ring = 1030 µm；pad 60×60、pitch 90 |
| 功耗 | 3.16–3.32 mW | **≈3.5–3.8 mW** | RA 不变、参考 +120 µW、数字 +100 µW、其他 +80 µW |
| FoM（100 kHz，core） | ≈190.9 | **≈193.8** | 速度翻倍、功耗只 +7%，同口径 +2.9 dB |

> **这一条是 10 MS/s 立项的全部理由**：共享 RA 与 reference 后，功耗不随速度线性翻倍，FoM 同口径升约 2.9 dB。代价是 DAC1 面积顶满 0.53，**任何后续 +0.01 mm² 都要重排 pad**。

## 8. 与交付树的对应

| 交付树节点 | 10 MS/s 变化 | 处理 |
|:---|:---|:---|
| `Sar20bTop` | 2× `Sar1Top` + `RaMux` + 1× `RingAmp3` + 2× `Sar2Ct` | 端口改 200 MHz、22 bit |
| `Sar1Top` | 内含 `SdacPool18`（18 片） | 已有节点，补 `CmpCoarse6b` 叶子 |
| `SdacPool18` | 8+8+2，两相 top 总线 | 已存在，netlist 落地 |
| `Sar2Ct` | **每相一套**（×2） | 复制实例，不改结构 |
| `RingAmp3` | **共享一套**，`RaMux` 选相 | 已存在 `RaMux` |
| `DigitalTop` | 两相调度 + `SliceShuffler` | 数字侧改，模拟只给握手 |
| `Dac2_12b` | 改名 `Dac2_11b`（11 bit） | 需同步 hierarchy/interfaces |

**必须同步改名的旧项**：`Dac2_12b` → `Dac2_11b`；`DOUT<20:0>` → `DOUT<21:0>`；`CLK 5 MHz` → `CLKP/CLKN 200 MHz`；`FS 5 Vpp` → `10 Vpp 差分`；`G=128` → `G=32`（旧 spec 全部作废）。

## 9. 布局大概怎么摆（G4 前的 floorplan 约定）

```
┌──────────────────────────────────────────────────────────┐
│  VINP/VINN pad（上边中央，对称）       CLKP/CLKN（下边中央）│
│  ┌───────────────┐        ┌───────────────┐              │
│  │  A 相 slice 池 │        │  B 相 slice 池 │              │
│  │  9×SdacSlice   │        │  9×SdacSlice   │              │
│  │  + SwSample    │        │  + SwSample    │              │
│  └──────┬────────┘        └───────┬───────┘              │
│         │ VTOPP_A                  │ VTOPP_B               │
│  ┌──────┴───────┐  参考/偏置  ┌────┴────────┐             │
│  │ Cmp1_A + 驱动 │  RefBuffer │ Cmp1_B + 驱动│             │
│  └──────┬───────┘  DynRefBuf  └────┬────────┘             │
│         └────────► RaMux ◄─────────┘                      │
│                     │                                      │
│              ┌──────┴──────┐                               │
│              │  RingAmp3   │  ← 共享，放中轴                │
│              └──┬───────┬──┘                               │
│        ┌────────┘       └────────┐                        │
│   ┌────┴─────┐            ┌──────┴────┐                    │
│   │ Sar2Ct_A │            │ Sar2Ct_B  │                    │
│   └──────────┘            └───────────┘                    │
│  ┌──────────────────────────────────────┐                 │
│  │  DigitalTop（下边，远离采样沿）        │                 │
│  └──────────────────────────────────────┘                 │
└──────────────────────────────────────────────────────────┘
```

**六条 floorplan 规则**：

1. **输入 pad 在上边中央，A/B 两池左右镜像**；两池到各自 pad 的走线等长（±50 µm），保证两相增益/寄生对称。
2. **RA 放中轴**，RaMux 紧贴 RA 输入；A/B 顶板到 RaMux 的两条路径等长（±20 µm），这是 50 ps 偏斜的物理前提。
3. **reference/DynRefBuf 放中轴上方**，到 A/B 两池的 VREF 走线等长；300 pF 去耦贴在 buffer 与池之间，不跨数字区。
4. **DigitalTop 放下边**，最后一次翻转距采样沿 ≥8 ns；数字电源单独 pad，地单独回流。
5. **时钟 pad 在下边中央**，200 MHz 差分对进 `ClkRx` 后走对称 H 树到两个 PHI_S 驱动器；PHI_S 驱动器单独供电脚。
6. **CmpCoarse6b 放中轴、紧贴输入**：63 个比较器的输入电容挂在 28 pF 节点上，走线总电容 ≤0.6 pF，否则粗量化增益误差 >4%。

**面积**：两池各 0.0765 mm²（9×3.456 pF 的电容+开关），RA/参考/数字按 §7 表；核心 0.53 已顶满，**版图阶段只允许在池内做密度优化，不允许再加功能块**。
