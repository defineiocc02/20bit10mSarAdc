> ### v1.3 最重要的一条：**τ_top 的定义没定，它决定 ss 角闭不闭合**
> 冻结了 Zout = 300 Ω、C_INC = 1 pF 之后，"τ_top = Zout·C_INC = **300 ps**"（架构组的算法）与"τ_top = Zout·(C_INC∥C_DAC2) = **150 ps**"（若 `CincCouple` 是**串联耦合**电容，从名字看是）差 2 倍，而这两个数一个能闭合、一个不能：
>
> | τ_top | ΦC2-SAR 标称需要 | ss/1.62 V/125 ℃ 需要 | 对 27.5 ns 窗 |
> |:---:|:---:|:---:|:---:|
> | **150 ps**（串联耦合） | 16.77 ns | **22.29 ns** | **+5.2 ✔** |
> | 200 ps（我 v1.1 的假设） | 19.06 ns | 25.27 ns | +2.2 ✔ |
> | **300 ps**（shunt 算法） | 23.64 ns | **31.22 ns** | **−3.7 ✘ 不闭合** |
>
> **⇒ 这是全项目唯一一个"口径差 2 倍、结果从闭合变不闭合"的项，必须在 G1 前用 PZ 仿真（不是 Zout·C 的粗略式）钉死。** 详见 §9.2b。

> 7. **新增 §9（验收模板）与 §10（定点语义说明书）**，后者是给 `ADC_C_MODEL v1.0` 的输入。
> 7b. **`CoefReg` 位宽 14 → 24 bit**（MSB 半组系数 ±512 u 在 Q4 下是 ±8192，**14 位有符号上限 ±8191 差 1 就溢出**；不是精度不够，是溢出）。
> 7c. **自纠两处口径**：① 采样抖动 1 ps 的误差是 **44.4 µV rms**（不是 62.8 µV 峰值），占 58 µV 功率的 58.7%，**"1 ps 物理不可能"作废**，0.5 ps 的理由改成"交易"；② M=7 的后果是**每 LSB2 区间留 1 u 死区 = 0.238 ppm 的锯齿型 DNL**（不是"折回 2–3 LSB2 噪声"）——**保 M 的主依据是 INL 不是 DR**。
> 7d. **`PP_START` 只能取 0–10 ns**（默认 0）：后处理 40 + 串行 60 = 100 ns vs 采集窗 110 ns；"帧后 50 ns"会冲进下一帧。且"帧后 10 ns 是顶板刚浮空"的**前提有误**——顶板浮空在 110 ns，帧后 10 ns = 210 ns，已过 100 ns 且开关闭合、顶板跟踪中（最不敏感）。
> 8. 自纠一处：重复项误差量级"8 u / 3.4 LSB_total"→ **4 u / 1.41 LSB_total**（验证组校正，且性质是锯齿型 DNL 不是噪声）。

> ### v1.1 变更（2026-11-07，与验证组对账后自纠两处）
> 1. **重复项公式改 2 倍**：$(2CNT-8)\to(CNT-M/2)\cdot(8/M)$。原式在 M=8、`CNT=8` 时多出 **4 u = 1.41 LSB_total**（我最初写"8 u / 3.4 LSB_total"是又错了 2 倍，验证组校正；症状是 1 LSB2 周期的锯齿型 DNL，不是噪声底抬升）。物理含义是"重复期只在 LSB2 内的 ±0.5 LSB2 范围内再分 M 档"，范围与 M 无关。

> 3. **新增**：`M` 可配 1/2/4/8（供硅上复现"3 dB/倍频"）、`ACC` 明确为 26 位（24 整数 + 2 小数保护，使舍入误差 0.088 LSB_total）、32 位配置口映射（§7.5）、与验证组 A1–A8 断言的对账（§7.6）。
> 4. 未变：帧表、位循环自定时、M=8 结构保证、D1=10 位、DAC2 11 位、22 位输出。

## 结论（先行）

1. **数字架构定为"1 个 200 MHz 同步壳 + 2 个自定时内核 + 5 级后处理流水"，帧长固定 90 ns（18 tick），相位边界 2.5 ns 半 tick 分辨率。** 一级/二级的位循环都走自定时，数字只给**固定长度包络 + 优先级截断**。这不是"图省事"——是因为 ΦC2 需要 500 MHz 等效速度，200 MHz 主时钟给不了，而 PLL 倍频会把抖动直接送到采样沿【设计选择】。
2. **D1 必须是 10 位，不是 11 位。** 决定性理由：LSB1 = 9.766 mV = 10 V / 2¹⁰ 已经把一级码宽钉死成 10 位；若强行 11 位，要么 LSB1 变 4.883 mV（所有 µV 数字差 6 dB、G、DAC2 量程全部推翻），要么出现两个系数对应同一个物理电容组（权重 {512…16,**16**,8,4,2,1}），LMS 回归矩阵秩亏 1，24 个系数里有 1 个永远漂。**"1 位内部冗余"在数字侧的体现是：把粗 LSB（c[0]）当作预置码用、当码位丢弃**，与细 MSB（f[4]）分时复用同一组 16 单位电容【算术】。
3. **最大的数字风险是 ΦC2 的 8× 重复窗口对 PVT 的鲁棒性，不是 SINC2 的位宽。** 1.25 ns/样本的栅格在 ss/1.62 V/125 ℃ 下只剩 3% 余量（快环标称 0.93 ns、最坏 1.21 ns）。处置：**M=8 由数字栅格硬保证，模拟快环慢下来的后果是"该拍保持、计一次 miss"，而不是 M 变成 7**——因为 M≠8 会让 SINC2 零点从 100 MHz 移到 114 MHz，把 RA 的 64 MHz 带内噪声折叠回来（这是丢整条噪声预算的错，而多一个 miss 只是丢 0.4 dB）【设计选择】+【算术】。
4. **数字功耗 1455 µW（占 3.57 mW 的 41%）不可能是"5 MS/s 下 3k 门组合逻辑"烧掉的。** 它等效于 **2.25 pF 的 200 MHz 开关电容**（1455 µW / 1.8² V² / 200 MHz）。所以功耗预算的正确写法是"**200 MHz 等效开关电容 ≤ 2.25 pF，其中常开部分 ≤ 0.6 pF**"，落到实现上就是"**200 MHz 时钟上的触发器 ≤ 280 个、自定时快环 ≤ 35 个**"。三条降功耗措施合计 −28%（→ 约 1050 µW），逐条见 §5.2【算术】。
5. **P2（10 MS/s）现在必须预留、但只预留 4 样东西**：双 bank 相位、切片调度器的参数化接口、每片 DEM 的映射层、PHI_S 的数字可控延时线（DCDL）。四样合计约 700 门 + 80 FF（约 3% 面积），不预留就要重写顶层。**其余（SINC2/重组/LMS）P2 一行都不用改。** 理由见 §5.5：P2 改变的是"谁来喂数据"，不是"怎么算"【设计选择】。

## 1. 数字架构总图

### 1.1 三层结构

```
                        ┌──────────────── 200 MHz 同步壳（常开，≤280 FF）────────────────┐
 CLK(200M) ────────────►│ ClkRstSync → TickGen(6b,0..39) → PhaseGen(半tick译码)          │
 RSTN ─────────────────►│                                    │ PHI_* (5V/1.8V)          │
 SPI(SDI/SCK/SDO/CS) ──►│ CoefReg(28×20b+16b)  ObsReg(计数/状态)  SpiSlave               │
                        └───────────┬────────────────────────────────┬───────────────────┘
                                    │ 包络 level                      │ 系数/配置
                    ┌───────────────▼──────────────┐   ┌─────────────▼──────────────┐
                    │ 自定时内核 #1：Sar1Ctrl        │   │ 自定时内核 #2：Sar2Ctrl     │
                    │  Flash63Dec → D1[9:5]         │   │  Sar2Sar11 → D2[10:0]      │
                    │  Sar1Fine5  → D1[4:0]         │   │  Rep8Gen   → DT[7:0]       │
                    │  (0–22.5 ns)                  │   │  (47.5–85 ns)              │
                    └───────────────┬──────────────┘   └─────────────┬──────────────┘
                                    │ D1[9:0]                        │ D2,DT + DONE2(同步后)
                    ┌───────────────▼────────────────────────────────▼──────────────┐
                    │ 后处理流水（5 MS/s 使能时钟，1 样本延迟，跑到下一个采样窗里）    │
                    │ Sinc2Dec → BitRecombine → GainScale → OutReg/串并接口           │
                    └────────────────────────────────────────────────────────────────┘
```

**三条时钟域**：

| 域 | 频率 | 内容 | 跨域机制 |
|:---|:---|:---|:---|
| `CLK200` | 200 MHz 常开（采样窗内可门控到 5 MHz 唤醒计数） | TickGen、PhaseGen、ObsReg、SpiSlave | — |
| `SELFTIMED` | 无时钟（延迟线 + 比较器 ready 电平） | Sar1Ctrl、Sar2Ctrl、Rep8 快环 | 包络电平（≥7.5 ns 宽，无亚稳）；回来时 `DONE` 经 2FF 同步 |
| `FS` | 5 MHz（`tick==0` 单拍使能） | Sinc2Dec、BitRecombine、GainScale | 由 `DONE2_SYNC` 置位、`ACC_DONE` 清 |

**与模拟的边界（只给电平与码，不给模拟量）**：数字不产生任何参考电压、偏置、模拟开关控制电流；唯一例外是比较器时钟由数字给（因为位循环节奏必须由数字定），但判决结果由模拟侧的就近锁存器送回。

**关于 `SerLvds`（主理人裁决：pad 上改串行 LVDS，数字核内部仍是 3 字节）**

| 项 | 值 | 依据 |
|:---|:---|:---|
| 每样本位数 | 22 数据 + `DOUT_VALID` + `FAULT` 标志 = **24 bit** | 正好 3 字节 |
| 比特率 | **400 Mbit/s**（DDR，随路时钟 = `CLK200` 200 MHz，**整数 1:1**） | 24 bit / 400 Mbit/s = **60 ns** |
| **为什么不是 200 Mbit/s**（v1.3 自纠，这是 P1 就有的 bug） | 采集窗只有 **110 ns**，后处理要 **40 ns**，剩 **70 ns** 给串行器；200 Mbit/s 需 **120 ns** → **后处理+串行 = 160 ns > 110 ns 窗，P1 就装不下** | 400 Mbit/s → 40+60 = **100 ns < 110 ns** ✔（余 10 ns） |
| pad | 2 对差分 = **4 脚**（数据 + 时钟） | 主理人算过 32 pad 才能进 0.53 mm² |
| 为什么不用 120 Mbit/s | 200/120 不是整数，要从 200 MHz 分频得 120 MHz 需要小数分频或 DLL | 用 /2 分频最干净 |
| **P2 顺带解决** | 400 Mbit/s 下 60 ns < 100 ns 周期 ✔ → **不再需要第二对 LVDS**（主理人裁的"多留 4 个 pad"可以退回，省 4 pad，版图组的 0.53 mm² 更宽） | 若 400 Mbit/s LVDS 在 180 nm BCD 上做不出来（要版图组确认驱动器带宽），退回 200 Mbit/s + 第二对：那时 P1 要**把串行器推到帧内**（50–59 ns 在 ΦC2 里，不推荐）或**延迟 2 个样本**。**所以 400 Mbit/s 是首选，不是优化** |
| 与转换帧的关系 | 串行器在每周期 tick 22–39 之外工作（采集窗内），`PP_START` 之后 40 ns 起 | 数字最后一次翻转距采样沿 ≥10 ns ✔（串行器在 300 ns 结束、边缘在 310 ns） |
| **I/O 功耗口径（版图组 2026-11-07 提醒，必须分列）** | **2 对 LVDS × 3.5–6 mA × 1.8 V = 12.6–21.6 mW**，是核心 3.16 mW 的 **4–7 倍** | **报告必须写"core 3.16 mW，I/O 另计 12.6–21.6 mW"**。论文的 3.57 mW 必然不含 I/O（业界惯例，FoM 只算核心）；若把 I/O 混进去，Schreier FoM 会差 5–8 dB。**不要为了账面好看降 LVDS 摆幅**（牺牲板级抗扰） |

### 1.3 复位策略

| 项 | 做法 | 判据 |
|:---|:---|:---|
| 全局 | RSTN 异步拉低（≥10 ns）、3FF 同步释放到 clk200，再扇出 | 释放后 2 周期内 `PHI_*` 全低，`TICK==0` |

## 2. 一级 SAR 控制

### 2.1 6 bit 粗量化器：63 比较器 flash 的数字侧

**接口**：模拟侧给 `TH[62:0]`（温度计，`TH[62]`=最正，上升沿单调）+ 一个 `TH_VALID`（所有 63 个比较器都再生完毕）。数字在 `TH_VALID` 后 ≤1.2 ns 出 `D1[9:5]`。

**译码结构（我的选择：MSB-first mux 树 + 1 级气泡钳位）**

不是"63→6 位二进制再装载"，而是**直接按二进制决策树取抽头**，这样 MSB 在 0.2 ns 就可用，可以和 DAC1 的 MSB 建立**流水起来**（arch §A.7 第 2 条要求的正是这个）：

| 级 | 抽头 | 气泡钳位 | 延迟 |
|:---:|:---|:---|:---:|
| 0 | `TH[31]` → `d5`（权重 512） | — | 1 门 |
| 1 | `TH[15]/TH[47]` 按 d5 二选一 → `d4` | `TH[a]&TH[a+1]` 与 `\|` 双路取中 | 0.2 ns |
| 2 | `TH[7,23,39,55]` → d3 | 同上 | 0.2 ns |
| 3 | `TH[3,11,…,59]` → d2 | 同上 | 0.2 ns |
| 4 | 16 选 1 → d1 | 同上 | 0.25 ns |
| 5 | 32 选 1 → d0 | 同上 | 0.3 ns |
| 合计 | | | **≈1.15 ns**（预算 1.2 ns） |

- **气泡（bubble）处理**：单气泡由"&/| 双路钳位"完全吸收（标准 flash bubble correction，1 级）；**双气泡**会被判成相邻码 ±1 粗 LSB（±16 LSB1）。**不静默吞掉**：`BUBBLE_CNT` 统计相邻 `TH[i]^TH[i-1]` 的跳变次数（应为 1，>1 即有气泡），并且 ±1 粗 LSB 的后果由 §2.3 的窗口判据兜住（+16 LSB1 刚好越界 → RA 削顶 flag 会亮）。
- **与"63 个动态比较器"的功耗接口**：63 个比较器由数字给时钟（`CMPQ_CLK`，与 `PHI_C0` 同沿），其判决必须在 2.0 ns 内完成 —— 这写进 §6 的合同第 1 条。
- **备选（若气泡统计不服管）**：8 组×8 位 popcount（组内真值计数）+ 8 路 CSA 求和，气泡完全无害，但延迟 2.0 ns、门数 ~450。**判别判据**：前仿统计 10⁶ 次粗量化，若 `BUBBLE_CNT>1` 的概率 >10⁻⁴，切 popcount；否则保留 mux 树（省 350 门 + 0.85 ns）。

### 2.2 5 bit 细搜索与"1 位内部冗余"

**位映射（这是本文最关键的一张表）**

| 阶段 | 决策 | 码字 | 权（单位 u = LSB2/8） | 驱动的物理电容组 | 说明 |
|:---|:---:|:---:|:---:|:---|:---|
| ΦC0 | c[5] | — | ±2¹²·2⁴ | 512 单位（**三电平**：VREF/VCM/VGND） | 三电平只作用 MSB【论文】 |
| ΦC0 | c[4]…c[1] | D1[9:6] | 2¹¹·2⁴ … 2⁸·2⁴ | 256/128/64/32 单位 | 二进制 |
| ΦC0 | **c[0]** | **丢弃** | 2⁷·2⁴ | **16 单位** | **只作预置，不作码位** |
| ΦC1 | f[4] | D1[5] | 2⁷·2⁴ | 上表的 16 单位（**时间复用**） | 覆盖 c[0] |
| ΦC1 | f[3]…f[0] | D1[4:1]… | 2⁶·2⁴ … 2³·2⁴ | 8/4/2/1 单位 | 二进制 |

> **D1[9:0]** = {c[5],c[4],c[3],c[2],c[1],f[4],f[3],f[2],f[1],f[0]}，10 位偏移二进制（中心 512）。
> 权重向量在 u 单位下是 **{2¹⁶,2¹⁵,2¹⁴,2¹³,2¹²,2¹¹,2¹⁰,2⁹,2⁸,2⁷}** —— 严格二进制，无分数位。

**"1 位内部冗余"怎么体现**：数字输出一个 `D1_BIT4_SEL` 信号。
- ΦC0 期间 = `c[0]`（把 16 单位组预置到粗量化的结果），
- ΦC1 期间 = `f[4]`（细搜索第一拍重新判决这一组）。
- 模拟侧只需一个 2:1 mux（16 单位组的底板驱动二选一），**不增加电容、不增加系数**。
- 捕获范围：5 拍二进制搜索权重 {16,8,4,2,1} LSB1 覆盖残差 **[−16, +15] LSB1**，即 ±1 粗 LSB（不对称 1 LSB1）→ 粗量化器只要有 3 bit 精度就够（arch §A.7 已证）。绝对边界 +16 LSB1 由 §2.3 的窗口判据拦住。

**为什么"丢弃"而不是"参与权重"**：若给 c[0] 一个独立权重，LMS 会看到两个系数（c[0] 与 f[4]）驱动**同一组 16 单位电容**——这两个回归量在物理上线性相关，协方差矩阵秩亏 1。后果不是精度差一点，而是 24 个系数里的一维会随噪声随机漂移（步长 × 迭代次数），掉电冻结后这一维失真 → INL 出现 ±16 LSB1 的台阶。**这条是可判的**：校准后看 INL 是否在每 16 LSB1 处有台阶（arch §B.7 判据 (a)）。

**一级码编码与到二级的接口**：`D1[9:0]` 偏移二进制，中心 512。数字同时送：
- `D1` 给 `BitRecombine`（权重 2^(k+12) u）；
- `D1` 给模拟的 `Dac1Mapper`（每个 bit → 对应电容组底板开关 + MSB 的 `TRI_MSB[1:0]`）。

### 2.3 D1 到底 10 位还是 11 位 —— 决策表

| 维度 | 方案 A：**D1 = 10 位** | 方案 B：D1 = 11 位（保留 c[0] 为独立码位） |
|:---|:---|:---|
| LSB1 | 9.766 mV ✔ 与仲裁备忘一致 | 4.883 mV（**与冻结参数冲突，全表 µV 差 6 dB**） |
| DAC1 位权（u 单位） | {2¹⁶…2⁷}，严格二进制 | {2¹⁶…2⁷,**2⁷**,2⁶…}，两个 2⁷（非二进制） |
| LMS 系数（DAC1 侧） | 10（+1 三电平半组，+1 可选 16 单位 trim） | 11，但秩 = 10 → **秩亏** |
| 重组加法器 | D1·2¹²（移位，0 门） | 需 11 输入非二进制加法树（+120 门） |
| 余差公式 | `ACC = D1·4096 + (D2−1024)·8 + (CNT−4)` ✔ 闭合 | 需重推 |
| 与 20.5 bit 校验 | 10+11+1.5−2 = 20.5 ✔ | 11+11+1.5−2 = 21.5 ✘ |

**选 A。** 唯一理由是算术闭合 + 秩条件，不是偏好。

### 2.4 一级状态机（`Sar1Ctrl`，含两个自定时内核）

| 状态 | 进入条件 | 输出动作 | 同沿优先级 | 退出/异常 |
|:---|:---|:---|:---|:---|
| `S1_IDLE` | RSTN / FRAME_RST / ΦC0 未起 | 全部 `CMP*_CLK` 低，`D1` 保持 | 最高 | `$rose(PHI_C0)` → `S1_FLASH` |
| `S1_FLASH` | ΦC0 起 | `CMPQ_CLK`↑（1 拍），等 `TH_VALID` | — | `TH_VALID` → `S1_FLASH_DEC`；`ΦC0 过 6.0 ns 未 TH_VALID` → `S1_TIMEOUT` |
| `S1_FLASH_DEC` | TH_VALID | mux 树逐级出 d5→d0；**d5 一出立刻驱动 512 组**（流水） | — | 1.2 ns 完成 → `S1_LOAD1` |
| `S1_LOAD1` | 译码完成 | 送 `D1[9:5]`、`D1_BIT4_SEL=c[0]`；等 DAC1 建立 1.94 ns | — | 建立完成 → `S1_FINE0` |
| `S1_FINE0..4` | ΦC1 起 / 上一拍完成 | 迭代替换：`CMP1_CLK`↑ → 等 `CMP1` ready → 更新 `D1[k]`，`D1_BIT4_SEL=f[4]`（仅第一拍切） | **`PHI_C1` 落优先于任何位** | 5 拍完 → `S1_DONE`；单拍 >2.5 ns → `S1_TIMEOUT` |
| `S1_DONE` | 第 5 拍完成 | `DONE1`↑（保持到 ΦC1 落），送 `D1[9:0]` | — | ΦC1 落 → `S1_IDLE` |
| `S1_TIMEOUT` | 任一超时 | `FAULT[TO1]` 锁存；`D1` 用当前值（未决位填 0） | — | ΦC1 落 → `S1_IDLE` |

**同沿优先级（必须写死，否则两个 always 抢同一个 D1 位）**：

```
优先级 1（最高）：RSTN 异步 → S1_IDLE
优先级 2        ：PHI_C0/PHI_C1 落 → 强制回 S1_IDLE（包络优先于位循环）
优先级 3        ：超时 → S1_TIMEOUT
优先级 4        ：比较器 ready → 推进位指针
优先级 5（最低）：DONE1 置位
```

`D1` 的每一位**只有一个 always 块可写**（写者是 `Sar1Ctrl` 的位指针寄存器译码出来的 one-hot 使能），禁止在 `D2DtXfer` 里再写。这是本项目必须写进编码规范的一条。

## 3. 二级 CT SAR 与 8× LSB repeating

### 3.1 11 bit 逐位控制：2 ns/bit 的预算不成立，必须非均分

任务给的拆法（比较器 0.6 / 逻辑 0.3 / DAC2 建立 0.9 / 余量 0.2 = 2.0 ns）**只对 LSB 半区成立**。原因：DAC2 的每一位建立时间与它自己的阶跃幅度成对数关系，MSB 的阶跃是 LSB 的 1024 倍。

> v1.1 我写"位 10–6 用 2.5 ns、位 5–0 用 1.8 ns = 23.3 ns"。**这个 23.3 ns 是标称值；固定延迟在 ss 角跟着工艺变慢 ×1.35 → 31.5 ns，超 27.5 包络 4 ns。** 逐位核算是每拍都过、但**总和过不了**（因为 23.3 比理论 19.1 多出的 4.2 ns 余量，在 ss 角被 ×1.35 放大成 5.7 ns）。
> **正确做法二选一**：① **比较器 ready 驱动**（首选，见 §3.3 的状态机，每拍一有 ready 就推进）→ 标称 19.1、ss 25.3，全程自适应；② 若 `CMP2` 给不出 ready 电平，用**逐位可编程延迟**（11 个 4 位码，标称合计 19.3，ss 26.1 ✔），代价约 200 门 + 44 FF。**两速方案废弃。**
> **两速的切换点（k=5）是可配置的**（`SPD_SEL[1:0]`），因为 τ_top 随 PVT 变、也随 C_INC 的实测值变。

**DAC2 的 p/n 双边码**：`Dac2Mapper` 把 `D2[10:0]` 转成 `D2_MASK`（差分两侧的底板控制，p 侧 = D2，n 侧 = 1023−D2 的补码形式），**两侧必须在同一沿翻转**（§6 合同第 3 条）。`Dac2Replica` 与主 DAC2 由同一组寄存器位经**对称、等长、等负载**的驱动器驱动，输出偏斜 ≤50 ps。

### 3.2 8× LSB repeating

**物理图像（这是本方案的核心判断）**：8× 重复**不是 8 次完整 SAR 转换**，而是"在 LSB2 这一个 bit 上做 8 拍一阶跟踪/ΣΔ，硬件上用 7 个单位电容的电荷共享做模拟平均，数字只提供 8 个固定栅格 + 累加 + 抽取"。三条证据：
- 论文式 $DO_3=V_{RES}+\frac1M\sum[n_{RA}+n_{CMP}+Q]$ 里的平均是**在 LSB 级噪声上**做的，不是重新量化 8 次【论文】；
- 若做 8 次完整 SAR，ΦC2 需要 8×19 ns = 152 ns ≫ 36 ns，物理上不可能【算术】；
- 1 阶 ΣΔ + **2 阶** SINC（不是 1 阶）正是抑制 1 阶噪声整形的标准组合 —— 这解释了"为什么是 SINC2"，也解释了 `DT[7:1]` 只有 **7** 个反馈电容（7 级量化 → 8 拍）【推断·高置信】。

**数字侧产出与接口**

| 信号 | 产生方式 | 时序 | 去向 |
|:---|:---|:---|:---|
| `REP_CLK[7:0]` | `Rep8Gen` 用 2.5 ns 半 tick 二分频出 1.25 ns 栅格，one-hot 8 拍 | 第 k 拍上升沿在 75.0 + 1.25k ns（k=0..7） | 模拟：比较器时钟 + 7 电容预置时序 |
| `REP_THERM[7:1]` | 运行计数 `REP_CNT` 的热码（不是最终值，是**实时**累加值） | 判决后 ≤0.25 ns 更新，**下一拍栅格前 ≥0.25 ns 稳定** | 模拟：7 个单位电容底板（模拟反馈） |
| `DT[7:0]` | 第 k 拍的比较器结果锁到 `DT[k]`（bit0 = 第 1 拍） | 第 8 拍栅格后 0.3 ns 全部有效 | 数字：`Sinc2Dec` |
| `REP_CNT[3:0]` | `ΣDT` 的运行值，0..8 | 同上 | 数字：诊断 + 模拟的热码源 |
| `REP_MISS[3:0]` | 某拍栅格结束时 `CMP2_READY` 仍低 → 保持上一拍值 + 计 1 | — | 观测/故障 |

**M 必须精确 = 8 怎么保证（三层保险）**

1. **栅格由数字硬性给定**：`REP_CLK` 是 8 个 one-hot 脉冲，来自 200 MHz 时钟二分频 + 半 tick，**不是自定时**。第 8 拍必然在 85.0 ns 结束，第 9 拍不存在。M=8 是**结构保证**，不是"希望"。
2. **模拟快环跑不完时保持，不跳拍**：若某拍环内没建立好，锁存器保持上一拍的判决（等效"重复采样一次"），`REP_MISS++`。**M 仍是 8**，SINC2 零点不动，代价只是这一拍的噪声增益少一点（最多 −0.4 dB）。
3. **`REP_MISS ≥ 2` 时打 `FAULT[REP]`**（样本仍输出、带 flag），由后端决定丢弃。**绝不截断成 M<8**。

> **为什么要死守 M=8（v1.3 重写：主依据是 INL，不是那 0.3 dB）**
>
> 我 v1.1 写"M=7 会折回 2–3 LSB2 噪声"，**这个量级站不住**（如果是噪声量，等于 DR 掉 3.5–5.7 dB，一个零点从 100 移到 114.3 MHz 不可能造成这么大）。验证组 2026-11-07 给了**算术确定的那一半**，我采纳：
>
> 若硬件的 1/M 缩放按 `M_CFG=8` 写死、而实际 `M_ACT=7` → `CNT∈[0,7]` → 插值项上限只到 $+3u$（应 $+4u$）→ **每个 LSB2 区间的顶端留 1 u 死区**：$1u = 2.384\,\mu V = 0.238$ ppm of FS = **INL 预算（1.5 ppm）的 16%**，且是**周期 = 1 LSB2 的锯齿型 DNL**。
>
> ⇒ **"保 M"的主依据是这条死区 + INL 锯齿，不是"少平均一次掉 0.3 dB"。** 若硬件改"跟 M 走"（除以实际 `CNT`），则无死区、无锯齿，只剩零点位移与噪声——那时保 M 的理由才回到噪声。**当前实现是"写死 8"，所以回归里要卡的是 INL 死区，不是 DR。**（验证组已把这四项列进 E3a：DR、INL 锯齿周期与幅度、死区码数、直流增益误差。）
>
> 零点论证仍然成立但只作定性：8 拍 1.25 ns → 长度 8 的 boxcar 零点在 100 MHz、2 阶 CoI 双零点同位置；M=7 移到 114.3 MHz。**这条解释"为什么 SINC2"，不解释"掉多少 dB"。**

### 3.3 异常路径：状态机与同沿优先级

| 异常 | 检测 | 处置 | 对输出的影响 |
|:---|:---|:---|:---|
| 比较器不 ready（ΦC2-SAR） | 拍内 2.5/1.8 ns 到期 | 该位**按 0 定**（不是按上一拍），推进指针，`TO_BIT++` | D2 该位误差 ≤0.5 LSB2·2^k |
| 比较器亚稳态 | 双沿锁存后 `P==N==0` 或 `P==N==1` | 判为 0，`META_CNT++`；不影响推进 | 同上（1 位） |
| ΦC2-SAR 超时（超过 27.5 ns 包络） | 包络比较器 | **立即停止搜索**，未决位填 0，`FAULT[TO2]`，**`DOUT_VALID=0`**；8× 重复照常从 75.0 ns 开始 | D2 尾部 ≤3 位错，≤7 LSB2 = 19.8 LSB_total。**`DOUT_VALID=0` 是必需的：否则错码会混进 INL 直方图，没人看得出来**（验证组 2026-11-07 意见，已采纳） |
| 8 拍跑不完 | 第 8 拍栅格 | 栅格强制结束，`DONE2` 照常 | M=8 保持，见 §3.2 |

| RA 削顶 | 模拟 `FAULT[0]` | 样本打 flag，**不丢**（保留信息供后处理判断） | 数据可能饱和 |
| 两个 bank 同时要 RA（P2） | `RaArb` | 后到者等一个 tick，`STALL_RA++` | 该 bank 的 ΦRA 起点推迟 → **P2 的时序否决项** |

> **`TO2` 的定位（v1.2 定稿）**：**防死锁兜底，不是允许的设计路径。** 验证组给的算术是硬的（v1.3 按 $(2^n-1)$ 修正，早先的 3.81/15.26 是按 $2^n$ 算错了 2 倍）——D2 尾部丢 1 位 = **19.07 µV = 1.91 ppm**（输入折算），是 1.5 ppm INL 预算的 **1.27 倍**；丢 3 位 = **133.5 µV = 13.35 ppm** = **8.9 倍**。**INL 是最大值指标**，哪怕只有 1% 的码发生截断，整颗芯片的 INL 指标就作废，而且只在 ss 角、只在某些码出现，是最难查的那类失败。
> 所以回归判据写成：**nominal + ss/1.62 V/125 ℃ 下 `TO_C2_CNT` = 0（10⁴ 次转换）**；触发时 `DOUT_VALID=0` 让硅测丢弃该点。**"M=8 > D2 低位"这个排序只在兜底路径上成立，正常路径上两者都必须为 0。**

**关于"两个 latch"的澄清（v1.3，回答验证组 2026-11-07 的 2 ns 冲突）**

架构侧在 ss 角的 25.3 ns 之外又加了 2 ns 的 latch，得到 27.3 ns（余 0.2）。**这是把两个不同的锁存器混成一个了：**

| 锁存器 | 在哪 | 耗时 | 是否在 ΦC2-SAR 的 27.5 ns 窗内 |
|:---|:---|:---:|:---:|
| **逐位判决锁存**（`D2[k]` 写入码寄存器） | 每一拍内 | **含在 0.9 ns 的"逻辑 0.3"里** | 是（已在 25.3 里） |
| **帧末交接锁存**（`D2/DT` → 200 MHz 域） | 第 8 拍栅格之后（85.0 → 85.3 ns） | **0.3 ns** | **否 —— 它落在 GUARD（85–90 ns，5 ns）里** |

**主理人 2026-11-07 终裁（v1.3 定稿）**：**ΦC2 = 37.5 ns（SAR 27.5 含 latch 0.5 + REP 10）、GUARD 5**，ss 25.8、余 1.7。**latch 2 ns 只作最坏角自检（27.3、余 0.2），不进验收**——触发只打 `FAULT[TO2]`、不判失败。曾短暂提过的 38.5/4 作废。

⇒ **验收口径：ΦC2-SAR 27.5 ns 窗 = 11 拍 25.3（含逐位判决锁存）+ 帧末交接 0.5 + 余 1.7。** 帧末交接的真实耗时是 **0.3 ns**（85.0→85.3），给 0.5 是取整；2 ns 只是最坏角自检。**请验证组的 E4b 判据按 25.3 + 0.5 = 25.8 签（余 1.7），不是按 27.3。**

**同沿优先级（`Sar2Ctrl` + `Rep8Gen`，必须写死）**

```
1（最高）RSTN / FRAME_RST      → ST_IDLE，REP_CNT=0
2        PHI_C2 落沿            → 强制 ST_IDLE（包络永远赢）
3        REP 栅格边界（HT 沿）  → 无论如何推进 REP_PTR；到 8 则 ST_DONE
4        ΦC2-SAR 包络用尽       → 冻结 D2 尾部，跳 ST_REP
5        比较器 ready           → 推进 D2 位指针（仅 ST_SAR）
6（最低）DONE2 置位
```

**`DT` 与 `D2` 的写者唯一性**：`D2` 只由 `Sar2Sar11` 的位指针 one-hot 写；`DT` 只由 `Rep8Gen` 的 `REP_PTR` one-hot 写。`Rep8Gen` 绝不写 `D2`。这条比任何时序余量都重要——同一寄存器两个 always 块抢写，后仿会偶发错码，且无法在 STA 里发现。

### 3.4 与 SINC2 的握手，以及"晚一拍"的代价

| 事件 | 时刻 | 说明 |
|:---|:---:|:---|
| `DT[7:0]` / `D2[10:0]` 全部有效 | 85.0 ns（第 8 拍后 +0.3） | 在 `PHI_C2` 落沿之后 0 |
| `DONE2` 进 200 MHz 域（2FF 同步） | 85.0 + 3 tick = **100.0 ns** | 2FF + 组合，跑在 200 MHz |
| SINC2 / 重组 / GainScale 完成 | 100 → 140 ns（8 个 FS 周期，留足） | 落在**下一笔采样的 110 ns 采集窗里** |
| `DOUT` 有效 | **第 n+1 笔的采样窗内**（总延迟 = 1 个样本） | 即"晚一拍" |

**晚一拍的代价（P1 / P2 不同）**

- **P1（200 ns 周期，90 ns 转换）**：采样窗 110 ns，后处理只需 40 ns → **代价 = 0**。这也是为什么 P1 不需要给后处理留转换时间。
- **P2（100 ns 周期，90 ns 转换）**：每 bank 只有 10 ns 的非转换时间 → **1 个样本延迟不够**，必须 2 个样本延迟（后处理排在"自己的转换结束 → 下一 bank 的转换窗口内"），也就是**需要 2 套后处理状态**（两份 `SINC2`/`ACC` 寄存器，约 +50 FF）。**这就是 §5.5 里"必须 P1 就预留"的第三项**。
- 接口速率：`DOUT` 在 5 MS/s 下每 200 ns 出一个 22 位字 → 110 Mbit/s。**22 根并行脚 + 5 V 域不现实**（见 §4.6），用 DDR 串行或 3 字节并口分 3 拍出。

## 4. 数字后处理链

### 4.1 统一单位 u —— 先把定点格式钉死

所有定点运算只用**一个单位**，避免每级都在换标度：

$$u \equiv \frac{\mathrm{LSB2}}{8} = 2.384\ \mu V = \frac{\mathrm{LSB_{total}}\cdot 2^{1.5}}{8} = \frac{\mathrm{LSB_{total}}}{2\sqrt{2}}$$

【算术】依据：LSB2/8 正好等于"8× 重复的 3 位增益"，即最细的一位；LSB_total = 2.828 u（2^1.5）。

| 量 | 在 u 单位下的值 | 位宽 | 说明 |
|:---|:---:|:---:|:---|
| D1 位 k（k=0..9） | 2^(k+12) | 2^21 | D1·LSB1 = D1·4096 u |
| D2 位 k（k=0..10） | 2^(k+3) | 2^13 | (D2−1024)·8 u |
| D2 中心 | 1024 → 0 | — | 偏移二进制，减 1024 后为补码 |
| D2 半量程 | ±8192 u | — | **= ±2 LSB1**，正是 2 bit 级间冗余 ✔ |
| CNT 项 | $(CNT - M/2)\cdot\frac{8}{M}$ u；M=8 时 = (CNT−4) u，CNT∈[0,8] | ±4 | 8× 重复的亚 LSB2 内插，**范围恒为 ±0.5 LSB2**（见下注） |
| 满量程 | ±4 198 404 u | 2²³ | 24 位整数 + 符号，含 1 位余量 |
| 1 LSB_total | 2.828 u | — | 非整数 → 输出端乘 1/√2（增益抽头） |
| 小数保护 | ×4（u/4 = 0.596 µV） | +2 | 使舍入误差 ≤0.088 LSB_total（满足"≤0.1 LSB"判据） |

> **M 的通用映射（M 可配 = 1/2/4/8，供验证做 M 扫描）**：重复期覆盖的永远是 LSB2 内的 ±0.5 LSB2，M 只改变步长：
>
> | M | 单拍栅格 | 步长 | CNT 范围 | 送入 ACC 的项 |
> |:--:|:--:|:--:|:--:|:---|
> | 1 | 10 ns | 1 LSB2 = 8 u | 0..1 | (CNT−0.5)·8 = 8·CNT − 4 |
> | 2 | 5 ns | LSB2/2 = 4 u | 0..2 | (CNT−1)·4 |
> | 4 | 2.5 ns | LSB2/4 = 2 u | 0..4 | (CNT−2)·2 |
> | 8 | 1.25 ns | LSB2/8 = 1 u | 0..8 | (CNT−4)·1 |
>
> 实现代价：一个 `8/M ∈ {8,4,2,1}` 的移位选择（3 位 mux）+ `CNT` 位宽 4 位不变（M=1 时只用 1 位）。**M 可配几乎不花钱，但让硅上能复现论文的"3 dB/倍频"M 扫描——这条我支持验证组的要求。**

### 4.2 SINC2：实现与位宽

**输入**：`DT[7:0]`（8 拍判决，bit0 = 第 1 拍）、`D2_S[10:0]`。
**功能**：$DO_3 = V_{RES} + \frac1M\sum_{k=0}^{7}\left[n_{RA,k}+n_{CMP,k}+Q_k\right]$，M=8。

"计数器 + 累加器"的二阶 CoI 落地（论文 Fig. 32 的做法）：

| 级 | 元件 | 位宽推导 | 位宽 |
|:---|:---|:---|:---:|
| 计数器 | `CNT = Σ DT[k]`（4 位加法树，8 输入） | 0..8 → 4 位 | **4** |
| 一阶累加 | `ACC1 += x[k]`，x[k]=±1（**跨拍不清零**） | 8 拍内 \|−8..8\| → 5 位 | **5** |
| 二阶累加 | `ACC2 += ACC1`（三角权重） | 8 拍最坏 8×8=64 → 7 位 | **7** |
| 反均值归一 | `×1/M`，M=8 时 `>>3`（**免费**）；M=1/2/4 时移位量随配 | +0 | — |
| 与 `V_RES` 合并 | `DO3 = (D2−1024)·8 + (CNT−M/2)·(8/M)` | ±8192 ±4 → 14 位 + 符号 = **15** | **15** |

> **关于"11+3 位"**：11 位来自 D2，3 位来自 M=8 的增益（LSB 变小 2³=8 倍）→ 11+3 = **14 位**，加符号 15 位。任务里说的 11+3 成立，但要记住这 14 位是**分辨率**，噪声只改善了 1.5 位（arch §A.3），所以后级要再除掉 2^1.5。
> **`ACC2`（7 位二阶 CoI）我保留但只作诊断输出**：因为它跨拍不清零时与 `CNT` 的组合形式不同（三角权重 vs 均匀权重），除非确认论文的 2 阶 CoI 是"跨转换连续"的，否则主路径用 `CNT` 的均匀平均。**这是【待确认】项**，判别方法见 §8 第 4 条。
>
> **一处已修正的公式错误（2026-11-07 自纠，v1.1）**：早先写的 $(2\,CNT-8)$ u 是错的——**范围会变成 ±1 LSB2，是正确值的 2 倍**。重复期的物理含义是"把 LSB2 内的残余在 ±0.5 LSB2 范围内再分 M 档"，所以 M=8 时正确式是 $(CNT-4)$ u（±0.5 LSB2 = ±4 u）。这个错会被 bit-exact C 模型在第一批定向向量里抓到（`CNT=8` 时 ACC 多出 **4 u = 9.54 µV = 1.41 LSB_total = 0.36 个噪声底**；注意是权重放大 2× 造成的**锯齿型 DNL（周期 1 LSB2）**，不是常数偏移也不是噪声抬升），所以必须在 C 模型冻结前改掉。

**零点位置**（必须写进验证判据）：8 个样本间隔 1.25 ns → 零点在 $f=1/(8\times1.25\,\mathrm{ns})=100$ MHz 及其整数倍。**M=8 保证零点为 100 MHz；M=7 则移到 114.3 MHz。**

**截断策略**：`(CNT−M/2)·(8/M)` 在 u 单位下是整数（M 为 2 的幂时步长必为整数 u）；`ACC` 带 **2 位小数保护**（单位 u/4 = 0.596 µV），所以最后的 `GainScale` 只需"加半 → 右移 → 饱和"，**最大舍入误差 0.088 LSB_total < 0.1 LSB_total**（验证组的 A6 判据可直接满足），rms = 0.051 LSB_total ≪ 3.93 LSB_total 噪声底 → **不需要噪声整形、不需要 dither**【算术】。
> **舍入的 tie-break 必须写进 C 模型**：用 round-half-away-from-zero（实现：`(x + 2^(n-1)) >> n` 对正数、对称取补对负数），**不要用 round-half-to-even**——否则 RTL 与 C 模型在 2^16 随机向量里必然出现 ±1 LSB 的分歧，等价性检查会假失败。

### 4.3 定点权重怎么组织（**v1.1 重写：名义值走移位，扰动走窄累加，√2 走增益抽头**）

先把三个因子摆清楚，这里我 v1.0 写错过一次，必须纠：

| 因子 | 值 | 会不会出现在数字通路里 | 硬件 |
|:---|:---:|:---|:---|
| **G = 32** | 2⁵ | **完全不出现在数字通路**。LSB2 已经是"折算到输入"的量（LSB2 = LSB1/512），/G 早在定义里吃掉了 | **0 门，0 常数** |
| **2^1.5 = √8** | 2.828 | 出现一次：ACC 的单位是 u = LSB2/8（过采样 3 位），但**输出** LSB 是 0.5 LSB_total = 1.414 u。1 u = 1/√2 个输出 LSB | 1 次乘常系（见下） |
| 1/√2 | 0.70710678 | Q16 = 46341 | 即"增益抽头" |

> **v1.0 的错误（必须留档）**：我写过"把 1/(G·2^1.5) = 1/90.51 并入每个系数，省掉乘法器"。这个算不通：①`G` 不该出现在这里（重复计入 32 倍）；②若每个系数都带 0.7071，最大的抽头（D1 的 bit9）在 Q8 下需要 $2^{21}\times0.7071\times2^8=3.8\times10^8$ → **29 位系数**，28 个 29 位抽头的加法树约 3500 门，比它想省的乘法器还贵。**结论反过来了：不要吸收。**

**修正后的方案（三段式）**

| 段 | 内容 | 位宽 | 门数 |
|:---|:---|:---:|:---:|
| ① 名义路径 | $\sum 2^{p_k} b_k$，$p_k\in\{12..21\}$(D1)、$\{3..13\}$(D2)、$0$(CNT) —— **全是 2 的幂，纯连线/移位，0 门** | 24 整数 | **≈0** |
| ② 扰动路径 | $\sum \Delta_k b_k$，$\Delta_k$ 为 14 位有符号 Q4（范围 ±32 u = ±1.7 ppm FS，覆盖 arch §B.7 的 19 ppm 失配的残差 + 增益误差） | 13 位有符号 | ~600 |
| ③ 合并 + 输出 | `ACC = (①+②) << 2`；`DOUT = sat(round(ACC × (46341+ΔW_G) >> 16))` | 26 → 22 | ~300（16 拍时序乘法，见下） |

- **② 用串行累加而不是全并行加法树**：2 抽头/周期 × 14 周期 = 70 ns @200 MHz，落在 110 ns 采集窗内（30 ns 余量）。13 位累加器的扰动和最大 $28\times32=896$ u，13 位（±4096）足够。若做成全并行 28 抽头 13 位树 ≈ 1750 门 → **串行省 1150 门**，代价是后处理延迟从 1 拍变 15 拍（在 110 ns 窗里无所谓）。
- **③ 的乘法不是额外开销**：它就是 **LMS 的增益抽头**。\(1/\sqrt{2}\) 的归一化和"RA 增益误差的校准"是同一件事（都作用在整个码的斜率上），所以一个乘法干两件事。16 拍时序乘法（26×17 位，300 门）在 200 MHz 下 80 ns 完成 ✔。
- **名义 ② 为 0 时整条链路 = 移位 + 加法**，这就是"未校准也能出码"的保证：`CoefReg` 复位值 = Δ_k 全 0、ΔW_G = 0。

- **LMS 训练后的系数怎么冻结（v1.3 位宽改正）**：`CoefReg` = **34 槽 × 24 位** = **816 bit** + `ΔW_G` 24 位 + 配置 35 位（主理人 2026-11-07 终裁）。
  > **为什么 14 位不够（我 v1.2 写的 14 位是错的）**：MSB 半组系数的训练范围是 **±512 u**，在 Q4 下是 **±8192**，而 **14 位有符号的范围是 ±8191 —— 差 1 就溢出**。所以 14 位连"刚好"都不满足。实际需要 ≥15 位有符号；**24 位是主理人裁的上限，给了 9 位余量**，同时也够 Q30/Q32 格式（若将来改定点）。**这条是主理人问"24 还是 14"时算出来的，不是凑整。****掉电不保持（片上无 NVM）**，上电后由系统重灌；复位值为全 0（= 名义），保证未灌系数出正确码、只是 DNL 回到未校准的 10–30 LSB_total。
- **P1 不做片上 LMS**（见 §4.6），所以"冻结"= 主机写一次，之后 `CAL_EN=0` 锁死写保护位。

### 4.4 位重组与输出格式

$$ACC = \left[\underbrace{\textstyle\sum_k 2^{p_k} b_k}_{\text{① 移位}}+\underbrace{\textstyle\sum_k \Delta_k b_k}_{\text{② 窄累加}}\right]\ll 2\ \ (\text{单位 } u/4)$$
$$DOUT = \mathrm{clamp}_{[0,\,2^{22}-1]}\!\left(2^{21}+\text{round}\!\left(ACC\times\frac{46341+\Delta W_G}{2^{16}}\right)\right)\quad(\text{单位 }0.5\,\mathrm{LSB_{total}},\ \textbf{偏置二进制})$$

- `ACC` 在 u/4 单位（2 位小数保护），`DOUT` 在 0.5 LSB_total 单位。
- **舍入 tie-break 见 §4.2 末注**（round-half-away-from-zero），C 模型必须同款。
- **为什么 2 位小数保护**：它把舍入误差压到 0.088 LSB_total，直接满足验证组 A6 的"≤0.1 LSB"。代价只有 2 个 FF。

**位宽与溢出（这里改一个数，有算术依据）**

| 项 | 值 | 依据 |
|:---|:---|:---|
| 满量程码数（LSB=0.5 LSB_total） | $2\cdot2^{20.5}=2^{21.5}=2\,965\,821$ | 【算术】 |
| 需要的位数 | $\lceil\log_2 2^{21.5}\rceil = 22$ | 21 位只能装 2²¹=2 097 152 码 → **装不下** |
| **`DOUT` 位宽与码制** | **22 位无符号偏置二进制**，中心 2²¹，LSB = 0.5 LSB_total = 3.372 µV | 【算术·修正】**必须无符号**：FS/2 = ±2^19.5 = ±1.483e6 码；22 位无符号容 ±2.097e6 ✔；22 位**有符号**的可用幅度只有 ±1.048e6 ✘ —— 与"21 位装不下"是同一个陷阱，架构组抓到 |
| 溢出保护 1 | `ACC[25:0]` 26 位有符号（24 整数 + 2 小数），满量程 4 198 404 u < 2²³ → **整数带 1 位余量**，`ACC` 不可能溢出 | 【算术】 |
| 溢出保护 2 | `DOUT` 钳位到 [0, 2²²−1] 并置 `FAULT[OVF]`、`OVF_CNT++`；此时 `DOUT_VALID` **仍为 1**（饱和是可解释数据，不是无效样本） | 设计 |

| 过载余量 | FS/2 = 1.483e6 码，中心 2²¹ = 2.097e6 → **每侧余 0.614e6 码 = 41 % FS** | 【算术】 |
| 20 bit 用户 | 系统侧右移 2 位截断；**芯片不另做 20 bit 模式** | 主理人裁决 |

> **给主理人的一句话**：`DOUT` 位宽从 21 改 22（或 LSB 从 0.5 改 1.0 LSB_total），请裁。这不是设计偏好——2^21.5 个码装不进 21 位。

#### 4.5.1 版图组提的"粗段系数 +7 个"——可以做，但要写清这是补丁不是解

版图组的观察：粗 6 位由 flash 温度计码直接装载，**每次 ΦC0 从 VREF 取的电荷是 popcount 的函数（0–35 pC 摆动）**，参考 droop 随码型变，所以它不是线性位权，一个 MSB 系数吃不下。

**我的判断（这是数字侧该说的话）：这本质上是参考建立问题，不是校准问题。**

- 一个 code-dependent 的 droop，如果它在 1.94 ns 的 DAC1 建立窗内**已经收敛到 <0.25 LSB1（2.44 mV）**，那它的影响就是"每一拍的有效参考略低一点"，可以被位权系数吸收；
- 如果它**没有收敛**，那它在每次比较时刻的残余是**该次转换码型的函数**，而码型逐样本变——这是"随信号变化的误差"，不是"固定失配"。**任何静态系数（哪怕 8 段）都只能吃掉它的平均值，吃不掉段内起伏。**
- 所以 8 段系数的效果取决于 droop 的形状是否"段内平坦"。**如果段内是单调爬升的（典型的 RC 未收敛尾巴），8 段系数能把 INL 从 15 ppm 压到 3–4 ppm，压不到 1.5 ppm。**

**所以我给两条，建议同时做**：
1. **数字侧接受 +7 个粗段系数**（8 段 × 1，段边界按粗码 8/16/24/…/56 切）。系数总数 27 → **34**，寄存器 34×14 = **476 bit** (+68 bit)，`CoefReg` 从 408 → 476 bit。校准点数 34×450 = **1.53×10⁴ 点 = 3.1 ms @5 MS/s**——一次性上电校准 3.1 ms 完全可接受（比 2.9 ms 只多 0.2 ms，因为每点多算 34 个系数，不是每点多跑一次）。
2. **但接口合同要加一条硬判据**（这才是真解）：**ΦC0 内任意码跳变（最坏是 011111 → 100000，电荷摆幅最大）下，VREF 在比较时刻的跌落 ≤0.25 LSB1 = 2.44 mV**。做不到就必须走版图组的选项 (i)（三电平互补，电荷恒定，但 +0.14 mm²）。**判据落在模拟侧，不是靠数字加系数兜。**

> 这与 arch 的第 1 号风险（"参考建立 + RA 输出阻抗 + DAC2 kickback 三者耦合"）是同一个根，我把它的量化判据落在这里。

**观测点数量与收敛**：arch §B.7 已算 $N=(\sigma_n/0.5\,\mathrm{ppm}\cdot A)^2\approx450$ 点/系数 → 28 系数 ≈ **1.3×10⁴ 点 = 2.6 ms @5 MS/s**。数字侧要提供的只有：**每样本导出 {D1[9:0], D2[10:0], CNT[3:0]} = 25 位**（原始码，不是重组后的）。主机算完写回。→ **片上不需要 LMS 引擎、不需要累加器。** 这是 1455 µW 预算能守住的关键【设计选择】。

- **接口选 SPI**：25 bit/样本 × 10⁴ = 250 kbit，@10 MHz = 25 ms；系数回写 408 bit + 配置 32 bit = 44 µs。**够快，且省引脚**。
- 若为了调试想要片上最小 LMS：只在 `CoefReg` 旁加一个 28 通道的"系数增量"寄存器 + 一个符号-符号乘法累加器，代价约 1800 门 + 400 FF（400 FF × 8 fF × 3.24 × 5 MHz = 52 µW），**我不推荐**——P1 阶段片上 LMS 只会让"校准到底对不对"这件事更难定位。

### 4.6 输出接口（这条会碰到引脚数，需要主理人裁）

22 位 @5 MS/s = 110 Mbit/s。三个选项：

| 方案 | 引脚 | 说明 | 推荐 |
|:---|:---:|:---|:---:|
| 22 位并行 + `DRDY` | 23 + 1 | 5 MS/s 下每 200 ns 一个沿；但 22 根 5 V/1.8 V 混合电平走线，串扰与地弹会直接喂回模拟 | ✗ |

#### 5.1.0 ΦRA 25 ns 的正确判据（采纳主理人的纠正）

主理人指出"ΦRA 25 ns 不要当成必须建立到 0.5 LSB2 的死线"，**这是对的，我 v1.1 把它当死线是错的**。CT 二级在 ΦC2 期间持续跟踪 RA 输出，2 bit 冗余本来就是为"未完全建立"准备的。正确的两条判据：

**判据 ①：ΦC2 起点余差落在 DAC2 量程内（≤2 LSB1 = 19.5 mV）**
一级细搜索结束后余差本身就 ≤0.5 LSB1 = 4.88 mV，**已经比 2 LSB1 小 4 倍**，所以这条在任何建立一个 corner 下都自动满足——它不是时序约束，是"一级没出错"的检查。若它被违反，说明错在一级（`TO_C1` / 气泡），不在 RA。

**判据 ②：每一位（2.36 ns）内的漂移 ≤0.5 LSB2 = 152 µV@顶板**
这条决定 INL，不决定是否丢码。RA 输出在 t 时刻的残余为 $V_0 e^{-t/\tau}$，$V_0$ 最大 0.625 V（±1.25 Vpp 的一半），单拍漂移：

$$\Delta_{bit}=V_0\,e^{-t/\tau}\left(1-e^{-2.36/\tau}\right)\le 152\ \mu V$$

| τ_RA | 25 ns 处单拍漂移 | 折 LSB2 | 判定 |
|:---:|:---:|:---:|:---|
| 2.4 ns（arch 标称） | 0.03 mV | 0.10 | ✔ 大量余量 |
| 3.0 ns | 0.09 mV | 0.30 | ✔ |
| 3.2 ns（标称 ×1.33 ≈ ss） | 0.13 mV | **0.43** | ✔ 勉强（余量 14%） |
| 3.6 ns（×1.5） | 0.29 mV | **0.95** | ✘ 超，INL 恶化 |

**结论**：ΦRA = 25 ns 在 ss 角（τ≈3.2 ns）**满足判据 ②，余量 14%**。所以"ΦRA 25 ns 是死线"这个说法我撤回；正确说法是：**ΦRA 25 ns 要求 ss 角 τ_RA ≤ 3.2 ns（即闭环极点 1/(2πτ) ≥ 50 MHz）**，这是模拟侧的签字段，数字侧不再从 ΦRA 抢时间。若 ss 角坏在这条，按主理人指示**加 RA 电流或加 ΦRA 时长，不动 M=8 的栅格**。

|:---|:---:|:---:|:---:|:---|
| ΦC1 | 13.0 | **12.88** | **−0.12** | 5 拍全自定时已是极限（每拍 0.78 cmp + 0.41 逻辑 + 0.97…0.19 建立 + 末位 2.75）。0.12 ns 余量在 ×1.35 这个估算本身 ±5% 的误差带内，**不能签**。×1.45 的栈式最坏角要 13.8 ns。 |
| ΦC2 | 36.0 | REP 固定 10 + SAR **25.8** = 35.8 | **−0.2** | REP 段 10 ns 会压（M=8 是结构不变量），能压的只有 SAR。SAR 在 ss 角自定时需 25.8 ns，剩给 latch/handoff 只有 0.2 ns。 |

**结论（已由主理人 2026-11-07 采纳）**：ΦC1 = **15 ns**、ΦC2 = **37.5 ns**（内部 27.5 SAR + 10 REP）、GUARD = **5 ns**，合计 90 ns。理由是这两段的"需要"是**模拟时间**（比较器再生、DAC2 建立），不随数字优化而缩短；而 GUARD 是唯一纯数字的段（只需要 0.5 ns 做 D2/DT 跨域），5 ns 已经给了 4.5 ns 的冗余。

> **注意：这张表里的"ss 需要"全部按 τ_top=200 ps 写的。若 τ_top 实际是 300 ps，ΦC2-SAR 在 ss 角要到 31.22 ns、超 27.5 窗 3.7 ns —— 见 §9.2b。这是当前唯一未闭合的项。**

**但 GUARD=5 ns 不影响 P2**（回应验证组 B5 与 arch "P1 帧要留 ≥10 ns 给 P2"）：
P2 的 90 ns 帧装在 **100 ns 周期**里，帧外自然有 10 ns（90 of 100），**这 10 ns 不是从 P1 的帧内 GUARD 挤出来的**。所以 P1 的 GUARD 取 5 还是 8.5，与 P2 的 bank 交接预算无关。arch 那句"留 ≥10 ns"应改成"P2 的周期必须 ≥100 ns"，那已经成立。

> 若主理人坚持 13/36：数字侧的后果是**明码写出**的——ss/1.62 V/125 ℃ 下 `TO_C1_CNT` 与 `TO_C2_CNT` 必然非零，一级余差会带 1–2 LSB1 误差进 ΦRA、二级 D2 尾部会被截（`DOUT_VALID=0` 的样本比例上升）。这不是"corner 下变差"，是"corner 下片子按规格不工作"。**我的建议是把 GUARD 收回 5 ns 换这两段各 2.5 ns。**

**哪些必须自定时、哪些可以同步**

| 路径 | 类型 | 理由 |
|:---|:---|:---|
| `PHI_*` 包络 | **同步**（200 MHz + 半 tick） | 帧长必须确定（90 ns 是全局合同），且要保证两个 bank 的 ΦS 相隔整周期 |
| 一级 flash 译码 | **同步**（跟随包络内 1.2 ns 预算） | 有明确的 1.2 ns 上限，用延迟线（`TH_VALID` → 延迟 → 抓）反而更稳 |
| 一级 5 拍细搜索 | **自定时** | 建立时间随 bit 权重变（0.19–0.97 ns），固定拍会浪费或不足（§2.5） |
| 二级 11 拍 | **自定时（两速）** | 建立时间随权重变 11 倍（0.14–1.53 ns）（§3.1） |
| 8× 重复栅格 | **同步（1.25 ns 硬栅格）** | M=8 是结构保证（§3.2） |
| 后处理（SINC2/重组/缩放） | **同步 FS** | 5 MS/s，有 110 ns 余量，完全不需要异步 |

### 5.2 数字功耗：把 1455 µW 翻译成可实现约束

**等效换算（这是本节的核心工具）**

$$C_{eq}=\frac{P}{V^2 f}=\frac{1455\,\mu W}{1.8^2\times200\,\mathrm{MHz}}=2.245\ \mathrm{pF}$$

即：**1455 µW ≡ 2.245 pF 的节点在 200 MHz 上每周期翻转一次**。等价写法：**280 个触发器**（每 FF 8 fF 含 CK 脚与线）全部跑 200 MHz。这个换算让"功耗预算"变成一个可以写进 RTL 评审表的东西：**数你挂在 200 MHz 上的 FF 个数**。

### 5.4 CDC 与复位、扫描

| 跨域 | 机制 | 位宽 | 亚稳预算 |
|:---|:---|:---:|:---|
| 比较器 `P/N` → 自定时锁存 | 单 FF + 延迟线定位采样点 | 2 | **要求比较器再生 τ ≤20 ps 且采样点在判决后 ≥0.6 ns**：BER ≈ $e^{-0.6/0.02}=e^{-30}=10^{-13}$，10 年 @5 MS/s ≈ 1.6×10⁹ 样本 → 期望 <1×10⁻⁴ 次误码【算术】 |
| `DONE2` 自定时 → 200 MHz | 2FF 同步 + 数据总线保持 ≥1 tick | 1 + 19 | 10 ns 同步延迟，落在 5 ns GUARD + 110 ns 采集窗内 ✔ |
| SPI → 200 MHz | 2FF + 握手，寄存器写入用"双缓冲 + 生效脉冲" | 408+32 | 慢域，无压力 |
| `ELIGIBLE` 模拟 → 数字（P2） | 2FF 同步 + 去抖（连续 2 次相同才认） | 18 | 无压力 |

**扫描/可观测性**

- 3 条链：`scan_200`（~230 FF）、`scan_st`（自定时域，~150 FF，扫描模式下强制 `IDLE` + 时钟由 SCK 给）、`scan_5v`（**不做**——5 V 电平转换器不可扫描，必须旁路成透明）。
- **自定时域的扫描要点**：扫描模式下所有自定时 FSM 必须能被塞到任意状态，同时延迟线旁路成固定值（`SCAN_BYPASS`），否则扫描移位会被自定时环路打断。
- 片上内建一个 **15 级环形振荡器**（30 门）用于监测自定时域的速度：读回其频率 → 就能判断"这一颗芯片的快环是快了还是慢了"，对定位 ss/corner 问题极有价值。成本 30 门。

### 5.5 P1 → P2 数字侧要改什么（以及必须现在预留的 4 样）

| 项 | P1 现状 | P2 变化 | 必须 P1 预留？ |

| 帧长 | 90 ns / 200 ns 周期（18 of 40 tick） | 90 ns / 100 ns 周期（18 of 20 tick） | 否（`PERIOD[5:0]` 可配即自动适配） |

### 5.6 数字噪声回灌模拟（给版图专家的硬要求）

数字是双向的：1039 个单位电容在 2 ns 内翻转 5 V，di/dt 会通过共享地/衬底喂回 DAC1 顶板。**数字侧能做的是"把边沿分类"**：

| 信号 | 边沿要求 | 为什么可以这样 |
|:---|:---|:---|
| `PHI_S` | **必须快**（<200 ps），抖动 <1 ps | 采样沿精度直接进 SNR（σ_t ≤1 ps，arch §B.6） |
| `PHI_C0` / `PHI_C1` / DAC1 位开关 | **允许限摆率**（0.5–2 ns 边沿），并加串联电阻 | 它们只需要在 1.94 ns 内建立到 0.5 LSB1，边沿慢一点不损失；慢边沿把 100 MHz 的 di/dt 压到 20 MHz 以下，避开 RA 的 64 MHz 噪声带 |
| `PHI_C2` / DAC2 位开关 | 中速（0.3–0.5 ns） | 位周期只有 1.8–2.5 ns，太慢来不及；但 DAC2 电荷量小（1 pF×0.5 V） |
| `HOLD` | 静态电平，只在帧边界翻转 | 无 di/dt 问题 |

**给版图的三条**：① 数字 1.8 V 与模拟 5 V 分域、独立地回流（星点在片外）；② 数字到 DAC1 的 11 条驱动线走"等长、远离顶板节点、下有屏蔽地"；③ `PHI_S` 的驱动器与其余 5 V 驱动器**分开供电脚**（同一个脚会把 C0/C1 的 di/dt 耦合到采样沿）。

| **0.5 ps（P1 档）** | 22.2 µV | **46.6 µV** | 53.6 µV（松 1.15×） |

| 12c | **P2 的 skew 微调改无源 cap-trim，不用有源 DCDL** | 数字只提供 **2×4 位静态码**（`CapTrim`），版图做 8 档 ×2 fF ≈ 0.5 ps/档、范围 0–4 ps 的电容阵列。理由（版图组）：180 nm 做不出 100 fs 单调 LSB；有源 DCDL 自身噪声 0.2–0.3 ps 会吃掉 0.5 ps 抖动预算的一半；6.3 ps 范围也补不了 8–20 ps 的系统偏斜 | 若系统偏斜真到 20 ps：加档位到 16 档（0–8 ps）或两级串接。**数字侧只是多 4 个 FF** |

| 16 | **数字活动窗口 `PP_START`：可取范围只有 0–10 ns，默认 0** | 版图组要求"挪到帧后 50–60 ns"以避开顶板浮空窗口。**算术上做不到**：后处理 40 ns + 串行器 60 ns = **100 ns**，而采集窗只有 **110 ns**（帧后 0 起算）；起步 50 ns 会在 350 ns 结束，**冲进下一帧的 ΦC0**。允许范围 **[0, 10] ns**，默认 **0** | **但那个"顶板刚浮空"的前提本身也把时间轴读错了**：帧后 10 ns = 绝对 210 ns，而顶板浮空发生在 **110 ns**（采样沿），已过去 100 ns。真正的"浮空后立刻有 di/dt"是**转换帧自己的 ΦC0**（110–117.5 ns，DAC1 5 V 翻转），那个动不了，靠 ≥0.5 ns 限摆率 + 独立供电脚压。**数字活动放在 200–300 ns（采样开关闭合、顶板被输入低阻钉住）已是最不敏感的位置；距下一个采样沿 10 ns ≥ 版图组要求的 8 ns ✔** |
| 17 | **数字耦合到顶板的预算：宽带 ≤9 µV rms + 单项同步杂散 ≤3 µV（= −121 dBc @FS）** | 数字以"边沿分类"配合（`PHI_S` 快、其余限摆率 + 串阻），并给出 `PP_START` 让硅上扫最优位置 | 若只能做到 30 µV：**DR 从 102.5 掉到 98.9 dB（−3.6 dB）**，且 8× 平均救不了（它只压 RA 放大相噪声，不压与转换同步的数字耦合）。这不是数字能修的，只能靠版图分域 + 限摆率 |
| 18 | **τ_top 必须用 PZ 仿真定，签收只认一个数：`τ_top@ss ≤260 ps`（⇔ `τ_top@nominal ≤200 ps`）** | 主理人已裁：手算按**串联耦合** → $\tau_{top}=Z_{out}(C_{INC}\parallel C_{DAC2})=300\,\Omega\times0.5\,\text{pF}=\mathbf{150\ ps}$（设计预期，ss 22.3 ns、余 5.2）。**但签收不许用手算**：DAC2 顶板注入 1 µA/100 ps 脉冲，看 400 ps 内恢复到 0.5 LSB2；扫 Zout（200/300/400 Ω）× C_DAC2（0.8/1.0/1.2 pF） | `τ@ss`：200 ps → 22.5 ns（余 5.0）；**260 ps → 25.3 ns（余 2.2，签收线）**；309 ps → 27.5 ns（余 0）；>260 ps 走路线 A（Zout 降到 200 Ω）。**注意验证组给的 290 ps 上限漏了 τ 在 ss 的劣化（他只把逻辑 ×1.35、没把 τ ×1.3），按 290 ps nominal 算 ss 要 30.7 ns，会超** |

**"数字降级"的统一原则（v1.2 收紧）**：**精度类**的降级（余差建立不足、replica 偏斜、M<8、参考 droop 未收敛）**一律不允许**——它们是整条传输函数的错。**速度类的降级（某拍超时、D2 尾部截断）也不再算"允许"**：只能是防死锁兜底，且必须 `DOUT_VALID=0`（验证组 2026-11-07 意见被采纳）。理由：D2 丢 1 位 = 3.81 ppm，是 1.5 ppm INL 预算的 2.5 倍；INL 是最大值指标，一个码截断就整条指标作废。

**仍缺两个数（阻塞时序档位，不阻塞 RTL 开工）**：RA 在 ΦC2 期的输出阻抗（按 300 Ω 排）、`C_INC` 冻结值（决定 τ_top）。两数一到，`SPD_SEL` 档位按 §9.3 重配，不动版图。

### 7.5 配置口（硅测 6 种组合的落地，32 bit，全部走 SPI）

验证组要求硅上能复现"tracking averaging 有效"这句话，必须能扫 M、能关、能注入。**可行的配置映射如下（我已按可实现性核过，没有做不到的）**：

| 位域 | 位宽 | 功能 | 实现代价 | 备注 |
|:---|:---:|:---|:---:|:---|
| `M_CFG` | 2 | 1/2/4/8 | 3 位 mux + 移位选择 | §4.1 的 M 表 |
| `TRK_BYP` | 1 | tracking averaging 旁路（等价于把重复项强制为 0，SINC2 不参与） | 1 个与门 | **与 M=1 不等价**：M=1 仍插值到 LSB2/1（±0.5 LSB2 范围、1 档），旁路则整项为 0（退化为纯 11 bit 二级）。验证组要区分这两个模式，判据不同 |
| `REP1_EN` | 1 | 重复段只走 1 拍（DAC2 只翻一次最低位） | 独立位（验证组 2026-11-07 要求） | **必须独立**：`M_CFG=1` 会把栅格也变成 10 ns、`CNT` 只有 1 档；`REP1_EN` 要的是"**栅格仍 1.25 ns×8、但 DAC2 只在第 1 拍翻、后 7 拍保持**"，这样才能把"重复带来的噪声增益"与"重复带来的码分辨率"分开测。此时 `CNT` 恒 = 8·DT[0]，`M_ACT` 仍 = 8 |

| `REF_EXT` | 1 | 告诉数字"参考已切外供"，禁用参考跌落相关的 FAULT 判据 | 1 位 | 硬件 mux 在模拟侧/封装侧，数字只改判据 |

| 合计 | **35 bit** | | 约 +60 FF | 走 SPI，不占 pad |

**三条我要提前说明的边界（免得判据写完再改）**：
1. `RA_PD` 与 `CODE_INJ_EN` 是**诊断模式**，此时 `DOUT` 的 INL/DNL 判据不适用（前者余差无意义，后者直接是码）。请把这两种模式的验收改成"噪声分布 / 后处理链一致性"。
2. `TRK_BYP`（整项为 0）与 `M_CFG=1`（插值 1 档）**语义不同**，不能合用一个判据。前者应该测出 DNL 变差（LSB2 台阶）、DR 掉约 1.5 bit；后者应该测出 DNL 改善但噪声增益只有 0 dB。
3. 动态改 `M_CFG` 会改变 `DOUT` 的 LSB 语义（因为 (CNT−M/2)·(8/M) 的步长变），**所以 M 扫描必须在每次改配置后重新做一次增益/失调标定**，否则会被误判成"tracking 无效"。这一条务必写进硅测流程。

> **形式等价的范围我同意验证组的划法**：`SINC2 + BitRecombine + GainScale` 对 C 模型做 2^16 随机 + 全边界（不用 2^24）。**但 C 模型必须由验证组拥有并冻结版本号**，我提供 RTL + 一份"定点语义说明书"（位宽、舍入、饱和、M 映射、tie-break）。两边各自独立写模型再比对，否则等价性检查退化成"抄一遍"。
> **进度属性**：我建议写成 `$rose(PHI_C2) |-> ##[0:38ns] DONE2`。**不是 40 ns**——REP 段固定在 85.0 ns 结束（ΦC2 起后 37.5 ns），`DONE2` 在 85.3 ns，判据留 38 ns 才有 0.7 ns 余量；写 40 ns 会把"REP 段整体晚到"这种真 bug 放过。
> **M 计数器的形式属性**：`M_ACT` 在 `PHI_C2` 落沿时 `== M_CFG`，且在任何中间状态下 `<= M_CFG`（"永不 >M"是结构性的，"永不 <M"只在正常完成路径上成立——超时/复位路径下 M 会小于 M_CFG，这是设计意图，形式属性要区分这两条路径）。

> **τ 的口径（v1.3 定死，版图组 2026-11-07 已按版图通路的接法确认）**：`CincCouple` 是**串联耦合**（RA 输出 → C_INC 1 pF → DAC2 顶板 → C_DAC2 1 pF 到地），顶板对地看到 $C_{INC}\parallel C_{DAC2}=0.5$ pF ⇒ **$\tau_{top}=Z_{out}\times0.5\,\text{pF}=150$ ps @300 Ω**。括号里的 300/390 ps 两栏是"按 $Z_{out}C_{INC}$ 粗算"的**对照值，不作判据**（验证组 2026-11-07 要求标注）。
> **两件事必须分清（v1.3 定稿）**：
> ① **本表的 τ 是"设计预期"，不是判据。** 顶板建立是两节点系统（$C_{DAC2}$ 到地、$C_{INC}$ 串 $Z_{out}$），单个 τ 本来就是简化；**签收只认"DAC2 顶板注入 1 µA/100 ps 脉冲、测 $V_T$ 的 63% 恢复时间"**，扫 $Z_{out}$（200/300/400 Ω）× $C_{DAC2}$（0.8/1.0/1.2 pF）。这一轮已经因为"纸面 τ"出了三次 2× 分歧（150/300/600），所以验证组把"τ 只许实测"写成硬要求，我同意。
> ② **τ 与 $Z_{out}$ 的换算是口径相关的，所以签收只写 τ、不写 $Z_{out}$**（见下表）。
>
> | 口径 | $Z_{out}$ | τ_nom | τ_ss | ss 需要 | 余量 |
> |:---|:---:|:---:|:---:|:---:|:---:|
> | **0.5 pF（串联，`CincCouple` 实际接法）** | 200 Ω | 100 ps | 130 ps | 19.3 ns | +8.2 |
> | | **300 Ω（合同值）** | **150 ps** | **195 ps** | **22.3 ns** | **+5.2 ✔** |
> | | 400 Ω | 200 ps | **260 ps** | **25.3 ns** | **+2.2（正好签收线）** |
> | 1 pF（$Z_{out}C_{INC}$ 粗算，作废） | 200 Ω | 200 ps | 260 ps | 25.3 ns | +2.2 |
>
> ⇒ **签收线 `τ@ss ≤260 ps` 在 0.5 pF 口径下对应 $Z_{out}\le400\ \Omega$，不是 200 Ω**（200 Ω 是 1 pF 口径的答案）。**这就是为什么签收只允许写 τ、不许写 $Z_{out}$** —— 写 $Z_{out}$ 会随口径漂 2 倍。合同保留 `Zout ≤300 Ω` 作为独立的保守项（它同时管 ΦRA 的 τ_RA ≤3.2 ns）。
>
> **两个 τ 不要混**：$\tau_{top}=150$ ps 用于**本表（ΦC2 的 11 拍）**；$\tau_{RAout}=Z_{out}(C_{INC}+C_{INC,rep})=300\,\Omega\times2\,\text{pF}=600$ ps 用于 **kickback 在 RA 输出上的衰减**（合同第 3 条 50 ps 偏斜 → 96 µV 那个数就是按 600 ps 算的）。**同一颗芯片两个都对，看的是哪个节点。**

**truncation 风险的分布（这条比总时间有用）**：τ=300 ps 时前 5 位（k=10…6）占 13.86 ns / 23.64 = **59%**。所以 ss 角一旦超时，**永远是前 5 位把时间吃光、截断落在末 3 位**。后仿必须记录 `BIT_T[k]` 才能区分"前段慢"与"末位慢"。

### 9.2b τ_top 的定义：差 2 倍，一端能闭合一端不能

| τ_top 的定义 | 数值 | 依据 | ss 需要 | 对 27.5 |
|:---|:---:|:---|:---:|:---:|
| $Z_{out}\cdot C_{INC}$（shunt 近似，架构组用） | **300 ps** | 300 Ω × 1 pF | **31.22** | **−3.7 ✘** |
| $Z_{out}\cdot(C_{INC}\parallel C_{DAC2})$（**串联耦合**） | **150 ps** | 300 Ω × 0.5 pF | **22.29** | **+5.2 ✔** |

**判别**：层次里这个电容叫 `CincCouple`——"Couple" 是**串联耦合**的意思，那它就是隔直/分压耦合，DAC2 顶板看到的对地电容是 $C_{INC}\parallel C_{DAC2}=0.5$ pF，**τ=150 ps**。若它是并联负载（顶板直接挂 1 pF 到地），则是 300 ps。

**这不影响数字（两种情况都按 ready 驱动自定时，代码一样），但它决定这颗芯片在 ss 角有没有 3.7 ns 的洞。所以必须在 G1 前定，办法只有一个：小信号 PZ 仿真+DAC2 顶板注入电流脉冲看 400 ps 内恢复（架构组已采用这个验收方式），不要用 $Z_{out}C$ 的粗略式。**

### 9.4 `DOUT` 延迟对齐（验证组的 FFT 脚本要用）

P1 时间轴（周期 200 ns = 40 tick）：

| 段 | tick | 时间（ns） | 内容 |
|:---|:---:|:---:|:---|
| 采集 | 0–21 | 0–110 | `PHI_S` 高；**采样沿 = 110 ns（`PHI_S` 下降沿）** |
| 转换帧 | 22–39 | 110–200 | ΦC0/ΦC1/ΦRA/ΦC2/REP/GUARD（帧内 0–90 ns） |
| 后处理 | 下一周期 tick 0–8 | +0–40 | SINC2 → 重组 → 缩放 |
| `DOUT` 有效 | 下一周期 tick ~8 | **+40 ns** | `DOUT_VALID=1` 与 `DRDY` 同拍 |
| 串行器出完 24 bit | 下一周期 tick 20 | **+100 ns** | 400 Mbit/s × 24 bit = 60 ns，接在后处理 40 ns 之后 |
| 距下一个采样沿（310 ns）余量 | — | **10 ns** | 满足"数字最后一次翻转距采样沿 ≥8 ns"（版图组 §6.4） |

**⇒ 延迟 = 1 个样本（200 ns）整**，不是 1.5 也不是 0.5。验证组的 FFT 采集脚本按"第 n 个输出对应第 n−1 个输入样本"对齐即可。

P2（10 MS/s，周期 100 ns）：每 bank 的帧 90 ns + 帧外 10 ns，后处理需要 ~80 ns 放不进 10 ns → **延迟 = 2 个样本（200 ns）**，且需要 2 套后处理状态（§5.5）。

### 9.5 `REP_MISS` 判据（采纳验证组的口径：按每帧 miss 数，不是"有 miss 的帧数"）

SINC2 会把 miss 平均掉，所以判据要落在"每帧 miss 数"上：

| 每帧 miss 数 | 平均后误差（= miss/8 LSB2） | 折输入 | ppm of FS |
|:---:|:---:|:---:|:---:|
| 1 | 2.38 µV | 2.38 µV | **0.24**（可忽略） |
| 2 | 4.77 µV | 4.77 µV | 0.48 |
| 4 | 9.54 µV | 9.54 µV | **0.95**（吃掉 INL 预算 2/3） |
| 8 | 19.07 µV | 19.07 µV | 1.91（超标） |

**判据**：名义/ff 下 10⁶ 次转换 `REP_MISS_CNT`=0；ss 角 **P(miss≥1) ≤1% 且 P(miss≥4) = 0**。

**追加一条更狠的**（验证组提，我同意并已做成可测）：**miss 率必须与码型无关** —— 按 16 个码区间做 χ² 齐性检验。因为如果 miss 只在接近满幅（RA 输出摆幅最大、DAC2 阶跃最大）时出现，它就从"随机噪声"退化成"码相关 INL"，严重一个量级。数字侧为此提供 `REP_MISS_CNT` 的**分码区间统计**：16 个 4 位计数器（每个码区间一个，共 64 FF），由 `D2[10:7]` 选中。**这是加 64 FF 换一条可判的指标，划算。**

> **关于 §6 第 17 条那个 9 µV 的口径**（这条容易算错，写死）：验收基准是 **26.51 µV**（实测含 RA 的总噪声底，对应 DR 102.5 dB），**不是 17.2 µV**（kT/C 上限，对应 106.3 dB）。相对 17.2 µV 会算出"9 µV 只掉 0.15 dB"的过松结论。核算：$\sqrt{26.51^2+9^2}=28.0\ \mu V$ → 0.48 dB；耦合 30 µV → 40.0 µV → **3.58 dB**。

> 附带一条 arch 的建议我也采纳：miss 发生时把**相位**（是第几拍）记下来。实现：`REP_MISS_PTR`（8 位，one-hot 或 4 位二进制记录最后一次 miss 的拍号）。这样"是位 10 之后 miss（=τ_top 变大）还是 REP 前段 miss（=比较器变慢）"可以直接读出来，不用重跑。

## 10. 定点语义说明书（给 `ADC_C_MODEL v1.0` 的输入，v1.3 新增）

> 用途：验证组拥有并冻结 C 模型；**两边独立写、再 bit-exact 比对**。本文只定义"语义"，不含实现。
> 版本：**`phase2_digital.md` v1.3 / 语义表 ver 1.0**。任何改动必须升版本号并写进变更记录。

### 10.1 常数（全部是精确值，不许在 C 里自行取舍入）

| 量 | 值 | 备注 |
|:---|:---|:---|
| $u$（内部单位） | $\mathrm{LSB2}/8 = 2.384185791015625\ \mu V$ | 二进制精确：$19.073486328125/8$，double 存不漂 |
| $\mathrm{LSB2}$ | $19.073486328125\ \mu V$ | $=9765.625\ \mu V/512$ |
| $\mathrm{LSB_{total}}$ | $6.743495761743045\ \mu V$ | $=10000\ \mu V/2^{20.5}$ |
| $\mathrm{LSB_{total}}/u$ | $2.8284271247461903 = 2^{1.5}$ | 输出端乘 $1/\sqrt2$ |
| 增益常数 | $46341 = \mathrm{round}(2^{16}/\sqrt2)$ | Q16；$46341/65536 = 0.70710754$（误差 $1.1\times10^{-6}$，$<0.003$ LSB_total，可忽略） |

### 10.2 输入码与范围（所有码都是**无符号偏移二进制**）

| 信号 | 宽 | 合法范围 | 中心 | 归一化 |
|:---|:---:|:---:|:---:|:---|
| `D1[9:0]` | 10 | [0, 1023] | 512 | 权重 $2^{k+12}$ u（k = 位号） |
| `D2[10:0]` | 11 | [0, 2047] | 1024 | 权重 $2^{k+3}$ u |
| `CNT[3:0]` | 4 | [0, M] | — | 项 $(\mathrm{CNT}-M/2)\cdot(8/M)$ u |
| `M_CFG` | 2 | {1,2,4,8} | — | 见 10.3 |

**越界处理（结构上不应发生，但 C 模型必须有定义）**：`D1>1023` or `D2>2047` or `CNT>M` → 视为**模型失效**，返回 `INVALID`，仿真器应报错而不是钳位。**不要静默钳位**——静默钳位会把 RTL 的位宽 bug 藏起来（这与我 §4.4 的输出钳位不是一回事：输出钳位是**规格允许**的饱和，输入越界是**不该发生**的）。

### 10.3 M 映射表（唯一的取整语义）

| M | 单拍栅格 | `CNT` 范围 | 送入 ACC 的项 | 实现 |
|:--:|:--:|:--:|:---|:---|
| 1 | 10.0 ns | [0,1] | $(\mathrm{CNT}-0.5)\cdot8 = 8\,\mathrm{CNT}-4$ | 左移 3 |
| 2 | 5.0 ns | [0,2] | $(\mathrm{CNT}-1)\cdot4 = 4\,\mathrm{CNT}-4$ | 左移 2 |
| 4 | 2.5 ns | [0,4] | $(\mathrm{CNT}-2)\cdot2 = 2\,\mathrm{CNT}-4$ | 左移 1 |
| 8 | 1.25 ns | [0,8] | $(\mathrm{CNT}-4)\cdot1 = \mathrm{CNT}-4$ | 不移 |

**注意一个漂亮的恒等式**：四种 M 下都是 $(\mathrm{CNT}\cdot 8/M - 4)$ u —— **常数项恒为 $-4$ u，与 M 无关**。所以放大器只需一次移位 + 一个固定 −4 的减法，C 模型也必须这么写（不要按 $M/2$ 算出一个随 M 变的小数，那会引入 0.5 的取整分歧）。

### 10.4 折算链（严格按此顺序，中间不截位）

```
ACC_int  = D1 * 4096 + (D2 - 1024) * 8 + (CNT * (8/M) - 4)      // 单位 u，整数
ACC_q4   = ACC_int * 4                                          // 加 2 位小数保护，单位 u/4
ACC_fin  = ACC_q4 + SUM(DW_k * b_k)                             // 扰动项，14 位有符号，单位 u/4
DOUT_raw = ACC_fin * (46341 + DW_G)                             // Q16 * Q4 -> 需右移 16+2
DOUT     = clamp( 2^21 + round_half_away(DOUT_raw / 2^18), 0, 2^22-1 )
```

| 量 | 位宽 | 类型 |
|:---|:---:|:---|
| `ACC_int` | 24 | 有符号（±4 198 404，< 2²³ ✔ 1 位余量） |
| `ACC_q4` / `ACC_fin` | 26 | 有符号（24 整数 + 2 小数） |
| `DOUT` | 22 | **无符号**，中心 2²¹ |

### 10.5 舍入：**round-half-away-from-zero**（禁用 round-half-to-even）

```
round_half_away(x):
    if x >= 0: return floor(x + 0.5)
    else:      return ceil(x - 0.5)
```
定点实现：`(v + 2^(n-1)) >>> n` 对正数；负数先取补、对称处理。

**理由（写进 C 模型注释）**：若用 round-half-to-even，RTL 与 C 在 2¹⁶ 随机向量里必然出现 ±1 LSB 分歧，且分歧只出现在"恰好半 LSB"的输入上——这类输入在定向边界向量里比例极高（D1=0/1023、D2=0/2047、CNT=0/8 都会落到半 LSB 上），等价性检查会假失败。

### 10.6 饱和（规格允许，与越界不同）

| 条件 | 行为 |
|:---|:---|
| `2^21 + v < 0` | `DOUT = 0`，`FAULT[OVF] = 1`，`DOUT_VALID = 1`（饱和是可解释数据） |
| `2^21 + v > 2^22-1` | `DOUT = 2^22-1`，同上 |
| 正常 | `FAULT[OVF] = 0` |

**过载余量**：FS/2 = ±1.483e6 码，中心 2²¹ = 2.097e6 → 每侧余 0.614e6 码 = **41% FS**。所以正常测试（FS−0.5 dB）永远不会碰到饱和；一旦 `FAULT[OVF]` 亮，说明输入真的超了 41%，不是数值问题。

### 10.7 异常路径下的取值（C 模型必须能复现这三种）

| 异常 | `D2` | `CNT` | `DOUT_VALID` | 说明 |
|:---|:---|:---|:---:|:---|
| 正常 | 完整 11 位 | [0,M] | 1 | |
| `TO2`（SAR 包络超时） | **未决位填 0**，已决位保留 | 正常（REP 照跑） | **0** | 确定性：从 MSB 起数，超时那一刻的位指针之后的位全 0 |
| `FAULT[ND2]`（`DONE2` 未到） | **上一帧的锁存值**（不是 0） | 同上 | **0** | 这里必须与 TO2 区分：ND2 是"没拿到新数据"，所以保持旧值最保守 |
| `META`（某位 P==N） | 该位按 **0** | 正常 | 1 | 单位错误，不丢样本 |
| `REP_MISS` | 正常 | 正常（保持的那一拍算重复计数） | 1 | 见 10.8 |

> **给 C 模型作者的一条经验**：`DOUT_VALID=0` 的样本在 C 模型里**也要算出来**（不要跳过），否则 RTL 与 C 的序列长度会错位，比对时全错。

### 10.8 `REP_MISS` 的语义（C 模型要建模）

某拍栅格末尾 `CMP2_READY` 仍低 → 该拍 `DT[k] = DT[k-1]`（第 0 拍则 = 0），`REP_CNT` 不增，`REP_MISS++`。
**`M_ACT` 仍然 = 8**（栅格数不变）。所以 `CNT` 是"8 拍里成功增了几次"，可能 < 8。

C 模型建模方式：给定一个 `miss_mask[7:0]`，`DT[k] = DT[k-1] if miss[k] else cmp_out[k]`，`CNT = popcount(DT)`。**注意 `CNT` 的上限仍是 M**，不需要额外钳位。

### 10.9 等价性检查的向量集（与验证组约定的范围）

| 类 | 数量 | 说明 |
|:---|:---:|:---|
| 随机 | 2¹⁶ | `D1`/`D2`/`CNT` 均匀随 + `M_CFG` 轮换 4 档 + `DW_k=0` |
| 边界 | 全组合 | `D1∈{0,512,1023}` × `D2∈{0,1024,2047}` × `CNT∈{0,M/2,M}` × `M_CFG∈{1,2,4,8}` = 81 组 |
| 半 LSB 专项 | 2¹² | 构造 `ACC_q4` 的低 2 位为 `10`（正好 0.5）的输入，专测 tie-break |
| 饱和专项 | 4 | `D1=1023,D2=2047,CNT=M` 与 `D1=0,D2=0,CNT=0` 两端 |
| 系数非零 | 2¹⁴ | `DW_k` 随机 ±、`DW_G` 随机 ±1% |
| 异常专项 | — | TO2 / ND2 / META / miss_mask 全 0 与单个 1 各一次 |

**判据：全部 bit-exact，不许有"误差在 X LSB 内"这种口径。** 定点模型唯一的正确性标准是逐位相同。
