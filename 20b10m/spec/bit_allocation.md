# 位分配与权重

> ⚠️ **已作废（2026-11-11）。** 本文的 20.5 bit / 11+12−2.5 / 5 Vpp 口径已被 `spec/SSOT.md` 取代。
> 现行：20.00 bit = 10+12−2，FS 10 Vpp，G=32。本文只作演进证据，不得作为设计输入。

> 历史目标：20.5 bit，FS = 5 Vpp 差分。本文把论文没写明的量化参数反推出来，作为 G1 冻结的基线。

## 1. 三个硬约束

| 约束 | 数值 | 来源 |
|:---|:---|:---|
| 总分辨率 | 20.5 bit | 论文 |
| 一级 | 11 bit（10+1：6 粗 + 5 细） | 论文 p.36–37 |
| 二级 | 12 bit，重叠 2.5 bit | 论文 p.36 + 20.5 = 11 + 12 − 2.5 |
| RA 输出摆幅 | ~1.7 V | 论文 p.41 |

由此可以唯一地定出增益与量程——**不需要问作者**。

## 2. 推导

```
总 LSB      = 5 V / 2^20.5        = 3.375 µV
一级 LSB1   = 5 V / 2^11          = 2.441 mV
二级量程 α  = 2^2.5               = 5.657  (即 ±2.83 LSB1)
二级输入范围 = ±2.83 × 2.441 mV    = ±6.91 mV  (差分 13.8 mVpp)
二级 LSB2（折算到输入）= α·LSB1 / 2^12 = 3.372 µV  ≈ 总 LSB ✅
```

这一步是自洽检验：**只有当 α = 2^2.5 时，二级最低位才正好等于总 LSB**，也就解释了为什么论文是 20.5 而不是 20 或 21。

## 3. 增益 G 的确定

RA 输出要摆到 1.7 Vpp：

```
G = 1.77 V / 13.8 mV ≈ 128 = 2^7  (42 dB)
```

三级 ring amp 分摊：A1 ≈ 20 dB、A2 ≈ 11 dB、A3 ≈ 11 dB，合计 42 dB —— 与论文的三级结构吻合。

| 量 | 值 |
|:---|:---|
| G | 128（42 dB） |
| DAC2 满量程（RA 输出） | 1.77 Vpp |
| DAC2 的 LSB（输出端） | 432 µV |
| DAC2 的 LSB（折算输入） | 3.37 µV |

> ⚠️ 若作者确认 G 不是 128，整张表按比例缩放；但 20.5 bit 与 1.7 V 摆幅这两个约束会把 G 锁在 128 附近。

## 4. 数字权重

以总 LSB 为单位：

```
DOUT = D1 × 2^9.5 + (D2 − 2^11)
     ≈ D1 × 724 + (D2 − 2048)          (2^9.5 = 724.08)
```

- `D1` 11 bit，`D2` 12 bit，偏置 −2^11 因为二级是双极性；
- 输出取 **21 bit**，最低位权重 = 0.5 LSB（即 20.5 bit 的"半位"）；
- 若系统只要 20 bit，直接右移 1 位截断。

## 5. 冗余怎么用

- 二级量程是 ±2.83 LSB1，而实际余差只需 ±0.5 LSB1（理想情况）→ **5.66 倍的量程冗余**；
- 这 2.5 bit 冗余就是允许 RA **不完成建立**、允许一级比较器有失调的余量；
- 代价：二级有效位数从 12 降到 9.5，正好对应 20.5 = 11 + 9.5。

**这正是论文的核心交易**：用二级的冗余换 RA 的建立时间与噪声，再用 8× 重复把噪声平均回来。
