# 模块卡与接口清单（候选 A）

> 对应 `spec/ADR-001_ARCH_DECISION.md` 的推荐方案。
> 每张卡同一格式：ID / 归属 / 输入输出 / 指标 / 依赖 / 现状 / 路线 / 交付物 / 验收 / 未决。
> **现状**用两轴：设计状态（候选/采用/弃用）× 实现状态（未开始/进行中/可运行/已验证/受阻）。

---

## 1. 模拟域

### M-A1 输入采样（pad/ESD + 自举开关）

| 项 | 内容 |
|:---|:---|
| 归属 | 模拟 |
| 不负责 | 采样时钟生成（数字）、CDAC 底板切换（M-A2） |
| 输入/输出 | VINP/VINN（0–5 V 单侧，差分 10 Vpp）→ 顶板采样电压 |
| 指标 | 采样带宽 >50 MHz（100 ns 内 14τ）；RON 全摆幅变化 ≤0.1%；电荷注入 ≤0.1 LSB1（0.98 mV） |
| 依赖 | PDK 5 V 器件模型 |
| 现状 | 设计状态：采用；实现：**未开始**（`SwSample5v` 网表存在但未实例化，bulk 接 GND） |
| 路线 | 5 V 厚栅自举（C_boot ≥1.5 pF，bulk 接源 + DNW），NMOS/PMOS 并联补偿 RON |
| 交付 | spec + CDL + 前仿（RON 扫描曲线、注入电荷） |
| 验收 | ΔRON/RON ≤0.1%（0–5 V）；注入 ≤0.1 LSB1；L1（单元前仿） |
| 未决 | 自举电容值与 DNW 隔离规则待 PDK |

### M-A2 差分 CDAC（18 片池，每片 128 单位）

| 项 | 内容 |
|:---|:---|
| 归属 | 模拟 |
| 不负责 | 码域生成（数字）、冗余解码（数字） |
| 输入/输出 | VINP/VINN、VREFP/VREFN/VCM、18 组底板命令 → 顶板电压 |
| 指标 | 单侧 27.6 pF（8 片活跃）；权重误差 <0.5 LSB1（前仿）；顶板寄生 ≤0.3 pF/片 |
| 依赖 | M-A1 采样、PDK MIM |
| 现状 | 设计：采用；实现：**受阻** —— 当前网表把同一组 `D<6:0>` 广播给 8 片（只有 7 bit 有效），三电平未接（`SEG<10:0>` 悬空） |
| 路线 | 3 bit unary（选 8 片之一）+ 片内 7 bit 二进制 + 1 termination；三电平用于 MSB |
| 交付 | 修好的 CDL + 1024 码逐码电荷扫描 |
| 验收 | LSB 台阶 = 1 单位（不是 8 单位）；DNL 单调；L2（网表前仿） |
| 未决 | U4：是否允许把固定接 VCM 的第 8 个 1C 改成可切换 |

### M-A3 比较器（SAR1 用）

| 项 | 内容 |
|:---|:---|
| 归属 | 模拟 |
| 不负责 | 判决逻辑（数字） |
| 输入/输出 | 顶板差分、CLK/READY → CMPP/CMPN |
| 指标 | 判决 ≤1 ns；失调 <1 LSB1（9.77 mV）；噪声 <50 µV；亚稳态率 <1e-9 |
| 依赖 | 1.8 V 薄栅或 5 V 厚栅（输入共模 2.5 V） |
| 现状 | 设计：采用；实现：**未开始**（`Cmp1` 网表存在，未仿真） |
| 路线 | 两级动态比较器（预放大 + 锁存），带失调修调 DAC |
| 交付 | CDL + 失调/噪声/延迟三组前仿 |
| 验收 | 判决 <1 ns；失调 <1 LSB1（修调后）；L1 |
| 未决 | 修调位数（取决于失调分布） |

### M-A4 余差放大器 RA（三级 ring amp，G=32）

| 项 | 内容 |
|:---|:---|
| 归属 | 模拟 |
| 不负责 | 余差采样（M-A5） |
| 输入/输出 | 余差 ±19.5 mV → 1.25 Vpp（差分） |
| 指标 | 建立 ≤17 ns 到 12 bit（τ ≤2.04 ns @4 pF）；输入噪声 ≤24 µV；A0 ≥50 dB；摆幅 ≥1.25 Vpp |
| 依赖 | PDK 1.8 V |
| 现状 | 设计：采用；实现：**受阻** —— `FiaA1/FiaA3` 的栅交叉接法使差模增益 ∝(gmn−gmp)≈0；A3 无偏置；EN 是空器件 |
| 路线 | A1 FIA 350 µA + A2 diode-load 60 µA + A3 FIA 10 µA，AZ 在 ΦC1 内完成 |
| 交付 | 修好的 CDL + DC 增益/带宽/噪声/建立四组前仿 |
| 验收 | A0 ≥50 dB；τ ≤2.04 ns；噪声 ≤24 µV；L1 |
| 未决 | C_AZ 容值；三级电流分配 |

### M-A5 CT2（C_INC + DAC2 12b + replica）

| 项 | 内容 |
|:---|:---|
| 归属 | 模拟 |
| 不负责 | 8× 重复的数字权重（数字） |
| 输入/输出 | RA 输出 → DAC2 顶板；D2 码 |
| 指标 | kickback 残差 ≤0.1 LSB2；DAC2 步长 = 1.0 LSB_total；C_top/P 匹配 ≤1% |
| 依赖 | M-A4、PDK MIM |
| 现状 | 设计：采用；实现：**受阻** —— replica 顶板被短到 VCM、注入电容接在不相连节点（抵消通路电学开断）；DAC2 参考电平未定 |
| 路线 | C_INC 1 pF 串联 + DAC2 1.78 pF（12 bit，27 fF 单位）+ replica 1:1 |
| 交付 | CDL + replica on/off 残差仿真 |
| 验收 | replica 抵消后 ≤0.1 LSB2 @50 ps 失配；L1 |
| 未决 | C_top 分段方案（6+6 / 7+5）与桥容 |

### M-A6 参考与偏置

| 项 | 内容 |
|:---|:---|
| 归属 | 模拟 |
| 输入/输出 | 外部 VREF → 5 V/1.8 V 两套参考 + VCM + 偏置电流 |
| 指标 | **droop <0.1 LSB1（0.98 mV）**；峰值电流 27.6 mA（MSB 切换 69 pC / 2.5 ns）；纹波 <2 µV |
| 依赖 | M-A2 的实际码型 |
| 现状 | 设计：采用；实现：**未开始**（`RefBuffer` 调整管无上拉、`DynRefBuf` 被接成"预充=精充"） |
| 路线 | 粗充（走 5 V）+ 精充（补最后 1–2 LSB）+ 300 pF 分组去耦；三电平把 MSB 电荷减半 |
| 交付 | CDL + 全码型 droop 波形 |
| 验收 | 段台阶 ≤0.25 LSB1；L2 |
| 未决 | **U5：单靠 300 pF + 预充不够（模型实测 23.6 LSB1），必须上分段参考或接受指标降级** |

### M-A7 时钟接收与相位驱动（CapTrim / PhaseSplit / PhiGen）

| 项 | 内容 |
|:---|:---|
| 归属 | 模拟 |
| 指标 | A/B 相 skew ≤1.6 ps；抖动 <1 ps；CapTrim 行程 ≥40 ps |
| 现状 | 设计：采用；实现：**不存在**（24 个块里没有这三个块，无 spec / 无网表 / 无面积） |
| 交付 | 三个新块的 spec + CDL |
| 未决 | CapTrim 档数与面积 |

## 2. 数字域

### M-D1 帧控制与相位生成

| 项 | 内容 |
|:---|:---|
| 归属 | 数字 |
| 不负责 | 采样沿的模拟驱动（M-A7） |
| 输入/输出 | CLK200 → PHI_C0/C1/RA/C2/AZ、HOLD、EN_RA |
| 指标 | 偏斜 ≤200 ps；相位 10/15/20/45 ns（2/3/4/9 tick） |
| 现状 | 设计：采用；实现：**可运行但口径旧** —— `DigitalTop.sv` 仍是 10/15/25/40 |
| 交付 | 改 2 行 + 仿真 |
| 验收 | 波形不重叠；`PHI_AZ` 早关 `PHI_RA` ≥2 ns |

### M-D2 切片调度（18 片，8+8+2）

| 项 | 内容 |
|:---|:---|
| 归属 | 数字 |
| 输入/输出 | `eligible[17:0]` → `acq_ids/conv_ids`（8×5 bit）、stall |
| 指标 | 上一采集组整体晋升；资格不足 stall 并保持状态 |
| 现状 | 设计：采用；实现：**有 Python 可运行版**（`behavioral` 外的 `model/digital_tech.py` 已验证：16 片两两交替、2 片备用、stall 正确）；**RTL 仍是 `base+8` 轮转** |
| 交付 | 把 Python 逻辑移植到 `SliceSched.sv` |
| 验收 | 8 帧内每片使用次数均匀；坏 2 片不 stall；只剩 7 片全 stall |

### M-D3 SAR1 搜索

| 项 | 内容 |
|:---|:---|
| 归属 | 数字（算法）+ 模拟（比较器/驱动） |
| 输入/输出 | 比较结果 → 10 位码 + 底板命令 |
| 指标 | 10 拍；半同步（帧包络 + 局部自定时） |
| 现状 | 设计：采用；实现：**可运行**（`Sar1Ctrl.sv` 240 行，重写版），但 `idx` 双 always 驱动 |
| 验收 | 端点/进位/冗余边界测试 |

### M-D4 SAR2 + 8× 重复

| 项 | 内容 |
|:---|:---|
| 归属 | 数字 |
| 指标 | 12 + 8 = 20 拍，45 ns 窗口（2.25 ns/拍） |
| 现状 | 设计：采用；实现：**可运行**（`Sar2Ctrl.sv` 207 行），但 `NB_D2=11` 要改 12；`Sinc2.sv` 的 `sum` 从不清零、`dt` 端口未用 |
| 验收 | 每帧 `done2` 恰好 1 次；20 轮全落位 |

### M-D5 重构与校准系数

| 项 | 内容 |
|:---|:---|
| 归属 | 数字 |
| 指标 | `D = D1·2^(N2−R) + (D2 − 2^(N2−1))`；系数 144 × 24 bit（偏差量编码） |
| 现状 | 设计：采用；实现：**权重错**（`ReconWeights.sv` 的 `<<3` 应按 BL-v3 重算，且缺 D1 偏置） |
| 验收 | 名义式逐码 bit-exact（Python 定点 vs RTL） |

### M-D6 输出帧与串行化

| 项 | 内容 |
|:---|:---|
| 现状 | 设计：**待确认**（U2）；实现：`FramePack.sv` 可用（缺 FRAME_TAKEN 节流）；`SerLvds.sv` **顶层未例化** |

## 3. 接口

### 3.1 模拟—数字边界（控制类）

| 信号 | 方向 | 宽度 | 极性/编码 | 时序 | 归属 |
|:---|:---:|:---:|:---|:---|:---|
| `PHI_S` | D→A | 1 | 高 = 采样 | 抖动 <1 ps | 数字出，模拟扇出（PhaseSplit） |
| `PHI_C0/C1/RA/C2` | D→A | 4 | 高有效 | 10/15/20/45 ns | 数字 |
| `PHI_AZ` | D→A | 1 | 高 = 自动调零 | 必须早关 `PHI_RA` ≥2 ns | 数字 |
| `HOLD` | D→A | 1 | 高 = 钉低栅极 | 覆盖整个转换窗 | 数字 |
| `SEL[17:0]` | D→A | 18 | 片选 | 换相只在顶板钉 VCM 窗内 | 数字 |
| `CMP1/2_START` | D→A | 2 | 脉冲 | 到模拟 ≤1 ns | 数字 |
| `CMP1/2_READY` | A→D | 2 | 脉冲，宽 ≥0.5 ns | 闭环握手，**不加 2FF 同步** | 模拟 |
| `CMP1/2_OUT` | A→D | 4 | 差分 | 判决后保持 | 模拟 |
| `FAULT[3:0]` | A→D | 4 | 电平，锁存 | 越界/超时/参考跌落 | 模拟 |

### 3.2 码域接口

| 信号 | 宽度 | 编码 | 合法范围 |
|:---|:---:|:---|:---|
| `D1` | 10 | 无符号 | 0..1023 |
| `D2` | 12 | 偏移二进制 | 0..4095（名义用 1024..3072） |
| `DT` | 8 | 二进制累加 | 0..255 |
| `DOUT` | 22 | offset binary | 0..2^22−1，中心 2^21 |
