## 2. 候选架构

三个候选只在**结构**上不同，共用的部分：差分 CDAC + SAR 逐位 + 级间放大 + 二级量化 + 数字重构。

### 候选 A（推荐）：10 DT + G=32 RA + 12 CT + 8× TA8，2 相部分交织

```
VINP/N → 18×差分切片（8 转换/8 采样/2 备）
       → 8 片顶板选通 → SAR1（10 判决，1024 单位/侧）
       → 余差（±2 LSB1 = 39.06 mVpp）
       → RA ×32（A1/A2/A3 三级）→ CT2（12 判决，C_INC + DAC2 + replica）
       → 8× 同笔重复 → 数字重构（20.0 bit）→ [可选 CAAZ] → 22 bit 输出
```

- 位账：`10 + 12 − 2 = 20.0`（LSL2 = LSB_total = 9.5367 µV，已用自洽断言锁死）
- 帧：90 ns 转换 + 10 ns guard，相位 10/15/20/45

### 候选 B（退路）：单通道，8 片固定，5 MS/s

同 A，但去掉交织池（18 → 8 片），不做双相位，帧周期 200 ns。

### 候选 C（不采纳）：11 DT + 12 CT − 2.5 = 20.5，2 相

一级 2048 单位（56 pF/侧），其余同 A。

## 4. 推荐

### 4.1 现行主线 = A（已确认），理由三条

1. **只有 A 同时满足 R1（20 bit）与 R2（10 MS/s）**。B 的速率只有 5 MS/s，直接不达标；C 的 RA 摆幅按 G=32 只有 0.88 Vpp，若提到 G=64 则余差噪声被放大 2 倍，等于把 C 的 3 dB 噪声优势还回去。
2. **A 的码域已经跑通**。`behavioral/` 包实测：σu=0 时 INL = **0.000 LSB20**，SNDR **122.06 dB / ENOB 19.98**；σu=0.2% 时 INL **43.3 ppm**。这不是文档，是运行结果。
3. **A 的面积/功耗代价可接受**：core 0.93 vs B 的 0.80，差 0.13 mm² 换 2× 速率。

### 4.2 为什么不采纳 C

C 唯一的好处是 kT/C 好 3 dB（12.2 vs 17.3 µV）。但代价：
- DAC1 面积 +0.14 mm²（core 0.93 → 1.07，超 R10 上限）；
- 一级多 1 拍，ΦC1 从 15 ns 需要 18 ns，只能从 ΦRA 借，RA 电流 +18%（功耗 +180 µW）；
- 位账从 20.0 变 20.5，但**传输码、重构权重、校准系数全部要重做**。

**用 3 dB 噪声换 0.14 mm² + 180 µW + 全链重做，不划算。** 而且我们当前的瓶颈不是噪声（27.4 µV 里 kT/C 只占 17.3），是 droop。

### 4.3 退路 B 的触发条件

若同时满足两条，则退 B：
1. 参考 droop 在 300 pF + 三电平 + 预充下仍 >1 LSB1；
2. 分段参考/局部去耦的方案被面积否决。

B 的代价是速率减半（5 MS/s），需要用户接受。

| 项 | 参考库（20b10mtask） | 本方案 A | 说明 |
